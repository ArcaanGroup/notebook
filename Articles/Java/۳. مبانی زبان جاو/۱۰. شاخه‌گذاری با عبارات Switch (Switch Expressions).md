### تغییر در نحو (Syntax) دستور Switch

در نسخه Java SE 14، می‌توانید از نحو دیگری که برای کلمه کلیدی `switch` بسیار راحت‌تر است استفاده کنید: **عبارت switch**.

چندین عامل باعث ایجاد این نحو جدید شده است:

- رفتار پیش‌فرض کنترل جریان بین برچسب‌های switch، **ریزش (fall-through)** است. این نحو مستعد خطاست و منجر به ایجاد باگ در برنامه‌ها می‌شود.
    
- بلاک switch به عنوان **یک واحد** در نظر گرفته می‌شود. این موضوع زمانی که بخواهید یک متغیر را فقط در یک `case` خاص تعریف کنید، می‌تواند مانع ایجاد کند.
    
- دستور switch یک **"جمله" (statement)** است. در مثال‌های بخش‌های قبل، در هر `case` به یک متغیر مقدار داده می‌شد. تبدیل آن به یک **"عبارت" (expression)** می‌تواند منجر به کد بهتر و خواناتر شود.

نحوی که در بخش قبل بررسی شد (دستور switch)، همچنان در Java SE 14 در دسترس است و معنای آن تغییر نکرده است. اما از Java SE 14 به بعد، نحو جدیدی به نام **عبارت switch** در دسترس است.

این نحو، ساختار برچسب switch را تغییر می‌دهد. فرض کنید دستور switch زیر را در برنامه خود دارید:

```Java
Day day = ...; // هر روزی
int len = 0;
switch (day) {
    case MONDAY:
    case FRIDAY:
    case SUNDAY:
        len = 6;
        break;
    case TUESDAY:
        len = 7;
        break;
    case THURSDAY:
    case SATURDAY:
        len = 8;
        break;
    case WEDNESDAY:
        len = 9;
        break;
}
IO.println("len = " + len);
```

با استفاده از نحو **عبارت switch**، اکنون می‌توانید آن را به شکل زیر بنویسید:

```Java
Day day = ...; // هر روزی
int len =
    switch (day) {
        case MONDAY, FRIDAY, SUNDAY -> 6;
        case TUESDAY                -> 7;
        case THURSDAY, SATURDAY     -> 8;
        case WEDNESDAY              -> 9;
    };
IO.println("len = " + len);
```

نحو برچسب switch اکنون به صورت `case L ->` است. اگر برچسب مطابقت داشته باشد، **تنها** کد سمت راست برچسب اجرا می‌شود. این کد می‌تواند یک عبارت واحد، یک بلاک یا یک جمله `throw` باشد. از آنجایی که این کد یک بلاک مجزا محسوب می‌شود، می‌توانید متغیرهایی را در آن تعریف کنید که مخصوص همان بلاک خاص باشند.

همان‌طور که در مثال قبل نشان داده شد، این نحو همچنین از چندین ثابت در هر `case` که با ویرگول از هم جدا شده‌اند، پشتیبانی می‌کند.

### تولید یک مقدار (Producing a Value)

از دستور `switch` می‌توان به عنوان یک **عبارت (Expression)** استفاده کرد. برای مثال، نمونه‌ای که در بخش قبل دیدیم را می‌توان به صورت زیر بازنویسی کرد:

```Java
int quarter = ...; // هر مقداری
String quarterLabel =
    switch (quarter) {
        case 0  -> "Q1 - Winter";
        case 1  -> "Q2 - Spring";
        case 2  -> "Q3 - Summer";
        case 3  -> "Q4 - Autumn";
        default -> "Unknown quarter";
    };
```

اگر در بلاک `case` تنها یک دستور وجود داشته باشد، مقداری که توسط آن دستور تولید می‌شود، توسط عبارت `switch` بازگردانده می‌شود.

#### استفاده از بلاک کد و کلمه کلیدی yield

نحو (Syntax) مربوط به زمانی که از یک **بلاک کد** استفاده می‌کنید، کمی متفاوت است. به طور سنتی، از کلمه کلیدی `return` برای نشان دادن مقدار تولید شده توسط یک بلاک کد استفاده می‌شود. متأسفانه این نحو در مورد دستور `switch` منجر به ابهام می‌شود. مثال زیر را در نظر بگیرید (این کد کامپایل نمی‌شود و صرفاً یک مثال است):

```Java
// توجه: این کد کامپایل نمی‌شود!
public String convertToLabel(int quarter) {
    String quarterLabel =
        switch (quarter) {
            case 0  -> {
                IO.println("Q1 - Winter");
                return "Q1 - Winter"; 
            }
            default -> "Unknown quarter";
        };
    return quarterLabel;
}
```

بلاک کدی که در صورت برابر بودن `quarter` با ۰ اجرا می‌شود، نیاز دارد مقداری را برگرداند. در اینجا از `return` استفاده شده است. اما اگر دقیق نگاه کنید، دو دستور `return` وجود دارد: یکی داخل بلاک `case` و دیگری در بدنه متد. ابهام اینجاست: آیا `return` اول به معنای خروج از کل متد است یا فقط خروج از `switch`؟ این ابهام باعث کاهش خوانایی و ایجاد خطا می‌شود.

برای حل این ابهام، نحو جدیدی ایجاد شده است: **دستور yield**. مثال بالا باید به شکل زیر نوشته شود:

```Java
public String convertToLabel(int quarter) {
    String quarterLabel =
        switch (quarter) {
            case 0  -> {
                IO.println("Q1 - Winter");
                yield "Q1 - Winter";
            }
            default -> "Unknown quarter";
        };
    return quarterLabel;
}
```

دستور `yield` جمله‌ای است که می‌تواند در هر بلاک `case` از یک دستور `switch` استفاده شود. این دستور همراه با یک مقدار می‌آید که همان مقدارِ عبارت `switch` دربرگیرنده خواهد بود.

### افزودن بند Default و جامعیت (Exhaustiveness)

بندهای `default` به کد شما اجازه می‌دهند تا مواردی را که مقدار انتخاب‌گر (selector) با هیچ‌یک از ثوابت `case` مطابقت ندارد، مدیریت کند.

#### مفهوم جامعیت (Exhaustiveness)

یکی از تفاوت‌های کلیدی این است که موارد یک **عبارت switch (Switch Expression)** باید **جامع** باشند؛ یعنی برای تمام مقادیر ممکن، باید یک برچسب مطابقت‌یافته وجود داشته باشد. در مقابل، **دستورات switch (Switch Statements)** نیازی به جامع بودن ندارند؛ اگر هدف انتخاب‌گر با هیچ برچسبی مطابقت نداشته باشد، دستور `switch` بدون انجام هیچ کاری و در سکوت خاتمه می‌یابد. این موضوع می‌تواند محلی برای پنهان شدن باگ‌ها در برنامه شما باشد.

در اکثر موارد، جامعیت با استفاده از یک بند `default` حاصل می‌شود. با این حال، در مورد عبارت `switch` روی یک **enum** که تمام ثوابت شناخته‌شده را پوشش می‌دهد، نیازی به اضافه کردن بند `default` نیست.

اما هنوز یک مورد وجود دارد که باید به آن رسیدگی شود: اگر کسی یک مقدار جدید به یک `enum` اضافه کند اما فراموش کند دستورات `switch` مربوط به آن را به‌روزرسانی کند چه می‌شود؟

برای مدیریت این حالت، کامپایلر در عبارات `switch` جامع، یک بند `default` برای شما اضافه می‌کند. این بند در حالت عادی هرگز اجرا نمی‌شود و تنها زمانی اجرا می‌شود که یک مقدار جدید به `enum` اضافه شده باشد، که در این صورت خطای `IncompatibleClassChangeError` را پرتاب می‌کند.

جامعیت، ویژگیِ عبارت‌های `switch` است که در دستورات `switch` سنتی ارائه نمی‌شود.

### نوشتن Case با علامت دونقطه (:) در عبارات Switch

یک عبارت `switch` می‌تواند از بلاک‌های سنتی `case L:` نیز استفاده کند. در این حالت، خاصیت **ریزش (fall-through)** همچنان اعمال می‌شود و مقادیر با استفاده از دستور `yield` برگردانده می‌شوند.

```Java
int quarter = ...; // هر مقداری
String quarterLabel =
    switch (quarter) {
        case 0 :  yield "Q1 - Winter";
        case 1 :  yield "Q2 - Spring";
        case 2 :  yield "Q3 - Summer";
        case 3 :  yield "Q3 - Summer";
        default: IO.println("Unknown quarter");
                 yield "Unknown quarter";
    };
```

### مدیریت مقادیر Null

تاکنون، دستورات `switch` مقادیر انتخاب‌گر `null` را نمی‌پذیرند. اگر سعی کنید روی یک مقدار `null` عملیات `switch` را انجام دهید، با خطای **NullPointerException** مواجه خواهید شد.

با این حال، **Java SE 17** یک ویژگی پیش‌نمایش (Preview Feature) ارائه کرده است که عبارت‌های `switch` را بهبود می‌بخشد تا اجازه استفاده از مقادیر `null` را بدهد؛ بنابراین می‌توانید انتظار داشته باشید که این وضعیت در نسخه‌های جدیدتر تغییر کند. این ویژگی به شما اجازه می‌دهد `null` را به عنوان یکی از برچسب‌های `case` مدیریت کنید:

```Java
// مثال از قابلیت‌های جدیدتر (Java 17+)
switch (obj) {
    case null  -> IO.println("مقدار نال است!");
    case String s -> IO.println("رشته است: " + s);
    default    -> IO.println("شیء ناشناخته");
}
```
