یک آرایه، یک شیء نگهدارنده (Container) است که تعداد مشخصی از مقادیر از **یک نوع واحد** را در خود ذخیره می‌کند. طول یک آرایه در زمان ایجاد آن مشخص می‌شود و پس از ایجاد، این طول **ثابت** (Fixed) می‌ماند. شما پیش از این مثالی از آرایه‌ها را در متد `main` برنامه "Hello World!" دیده‌اید.

هر مورد در یک آرایه، یک **المان** (Element) نامیده می‌شود و هر المان از طریق **اندیس عددی** (Index) خود قابل دسترسی است. همان‌طور که در تصویر بالا نشان داده شده، شماره‌گذاری از **۰** شروع می‌شود. به عنوان مثال، ششمین المان در اندیس ۵ قابل دسترسی خواهد بود.

برنامه زیر با نام `ArrayDemo` یک آرایه از اعداد صحیح ایجاد کرده، مقادیری را در آن قرار می‌دهد و هر مقدار را در خروجی چاپ می‌کند:

```Java

        anArray[3] = 400;

        anArray[5] = 600;
        anArray[6] = 700;
        anArray[7] = 800;

        System.out.println("Element at index 1: " + anArray[1]);
        System.out.println("Element at index 2: " + anArray[2]);
        System.out.println("Element at index 3: " + anArray[3]);
        System.out.println("Element at index 4: " + anArray[4]);
```

در شرایط واقعی برنامه‌نویسی، شما احتمالاً از ساختارهای **حلقه** (Looping constructs) برای پیمایش در هر المان آرایه استفاده می‌کنید، به جای اینکه هر خط را به صورت جداگانه مانند مثال بالا بنویسید. با این حال، این مثال به خوبی ساختار دستوری آرایه را نشان می‌دهد. شما در بخش «جریان کنترل» با حلقه‌های `for` ،`while` و `do-while` آشنا خواهید شد.

## تعریف متغیر برای ارجاع به یک آرایه

در برنامه‌ای که بررسی کردیم، آرایه‌ای به نام `anArray` با خط کد زیر تعریف شده است:

```Java
// تعریف یک آرایه از اعداد صحیح
int[] anArray;
```

مانند تعریف متغیر برای سایر انواع داده، تعریف یک آرایه نیز از دو بخش تشکیل شده است: **نوع آرایه** و **نام آرایه**.

- **نوع آرایه:** به صورت `type[]` نوشته می‌شود که در آن `type` نوع داده‌ی المان‌های داخل آرایه است. براکت‌ها (`[]`) نمادهای خاصی هستند که به کامپایلر می‌فهمانند این متغیر قرار است یک آرایه را نگه دارد.
    
- **اندازه آرایه:** توجه داشته باشید که اندازه آرایه بخشی از نوع آن نیست (به همین دلیل داخل براکت‌ها خالی است).
    
- **نام آرایه:** می‌تواند هر نام دلخواهی باشد، به شرطی که از قوانین و قراردادهای نام‌گذاری (که قبلاً در بخش متغیرها خواندیم) پیروی کند.


**نکته مهم:** صرفاً تعریف متغیر (Declaration)، آرایه را ایجاد نمی‌کند؛ بلکه فقط به کامپایلر اطلاع می‌دهد که این متغیر در آینده به آرایه‌ای از نوع مشخص شده اشاره خواهد کرد.

## ایجاد، مقداردهی اولیه و دسترسی به آرایه

یکی از راه‌های ایجاد آرایه، استفاده از عملگر `new` است. در برنامه `ArrayDemo` که بررسی کردیم، دستور زیر حافظه کافی برای ۱۰ عنصر عدد صحیح را اختصاص داده و آن را به متغیر `anArray` متصل می‌کند:

```Java
// ایجاد یک آرایه از اعداد صحیح

```

اگر این مرحله را فراموش کنید، کامپایلر با خطایی شبیه به این مواجه می‌شود و برنامه اجرا نخواهد شد:

`ArrayDemo.java:4: Variable anArray may not have been initialized.`

(متغیر anArray ممکن است مقداردهی اولیه نشده باشد).

سپس برای مقداردهی به هر خانه از آرایه، از اندیس استفاده می‌کنیم:

```Java

anArray[2] = 300; // و به همین ترتیب...
```

دسترسی به هر عنصر نیز دقیقاً به همین صورت و با استفاده از اندیس عددی آن انجام می‌شود:

## ایجاد آرایه‌های چندبعدی

از آنجایی که یک آرایه می‌تواند هر نوع «مرجع» (Reference) را در خود نگه دارد و خودِ آرایه نیز یک نوع مرجع است، شما می‌توانید به‌راحتی **آرایه‌ای از آرایه‌ها** ایجاد کنید. به این ساختار، **آرایه چندبعدی** گفته می‌شود.

شما می‌توانید این آرایه‌ها را با استفاده از دو یا چند مجموعه براکت تعریف کنید، مانند `String[][] names`. در نتیجه، برای دسترسی به هر المان، باید از همان تعداد اندیس استفاده کنید.

#### تفاوت ساختاری در جاوا

در زبان جاوا، یک آرایه دو‌بعدی در واقع آرایه‌ای است که اعضای آن، خودشان آرایه‌های دیگری هستند. این موضوع با زبان‌هایی مثل C یا Fortran متفاوت است:

- در **C**: یک آرایه دوبعدی یک ناحیه پیوسته از حافظه است.
    
- در **جاوا**: خودِ آرایه یک ناحیه پیوسته است، اما چون آرایه دوبعدی «آرایه‌ای از مراجع» است، لزوماً تمام داده‌ها در یک بلوک حافظه پشت سر هم نیستند.

#### آرایه‌های دندانه‌دار (Jagged Arrays)

یکی از پیامدهای این ساختار در جاوا این است که **طول سطرها می‌تواند با هم متفاوت باشد**. به این نوع آرایه‌ها، آرایه‌های **نامنظم** یا **دندانه‌دار (Jagged)** گفته می‌شود.

به مثال زیر توجه کنید:

```Java
class MultiDimArrayDemo {
    public static void main(String[] args) {
        String[][] names = {
            {"Mr. ", "Mrs. ", "Ms. "}, // سطر اول با ۳ عضو
            {"Smith", "Jones"}          // سطر دوم با ۲ عضو
        };
        
        // خروجی: Mr. Smith
        IO.println(names[0][0] + names[1][0]);
        
        // خروجی: Ms. Jones
        IO.println(names[0][2] + names[1][1]);
    }
}
```

در این مثال:

- `names[0]` به آرایه‌ای با طول ۳ اشاره دارد.
    
- `names[1]` به آرایه‌ای با طول ۲ اشاره دارد.

## استفاده از ویژگی Length در آرایه‌ها

در نهایت، شما می‌توانید از ویژگی داخلی `length` که برای هر آرایه‌ای تعریف شده است، برای تعیین اندازه (تعداد المان‌های) آن استفاده کنید. کد زیر اندازه آرایه را در خروجی چاپ می‌کند:

```Java
IO.println(anArray.length);
```

این ویژگی به‌ویژه در **آرایه‌های چندبعدی دندانه‌دار (Jagged Arrays)** اهمیت حیاتی دارد؛ چرا که هر سطر می‌تواند طول متفاوتی داشته باشد. کد شما نباید فرض کند که تمام زیر-آرایه‌ها هم‌اندازه هستند، بلکه باید مانند متد زیر به ویژگی `length` متکی باشد:

```Java
void displayBidimensionalArray(String[][] strings) {
    // حلقه اول برای پیمایش سطرها (آرایه اصلی)
    for (int arrayIndex = 0; arrayIndex < strings.length; arrayIndex++) {
        // حلقه دوم برای پیمایش ستون‌ها (هر زیر-آرایه به صورت مجزا)
        for (int index = 0; index < strings[arrayIndex].length; index++) {
            IO.print(strings[arrayIndex][index] + " ");
        }
        IO.println(); // رفتن به خط بعد پس از اتمام هر سطر
    }
}
```

شما می‌توانید متد بالا را با آرایه‌ای که سطرهای آن طول نامساوی دارند فراخوانی کنید:

```Java
String[][] strings = {
      {"one"},
      {"Maria", "Jennifer", "Patricia"},
      {"James", "Michael"},
      {"Washington", "London", "Paris", "Berlin", "Tokyo"}
};

displayBidimensionalArray(strings);
```

**خروجی این کد به صورت زیر خواهد بود:**

```
one 
Maria Jennifer Patricia 
James Michael 
Washington London Paris Berlin Tokyo 
```

---

### نکات کلیدی برای یادآوری:

- **ثابت بودن:** مقدار `length` پس از ایجاد آرایه قابل تغییر نیست.
    
- **تفاوت با متدها:** در آرایه‌ها، `length` یک ویژگی (Property) است، بنابراین برخلاف کلاس `String` که از `()length.` استفاده می‌کند، در آرایه **بدون پرانتز** نوشته می‌شود.
    
- **آرایه‌های چندبعدی:** `strings.length` تعداد سطرها را برمی‌گرداند و `strings[i].length` تعداد ستون‌های همان سطر خاص را.

## تمرینات محاسبات آرایه

### ۱. محاسبات آماری روی آرایه

این بخش شامل پیدا کردن مجموع، میانگین، و مقادیر حدی (Max/Min) است.

```Java
import java.util.Arrays;

int[] values = {12, 8, 15, 3, 9, 21};
int sum = 0;
int max = values[0];
int min = values[0];

// استفاده از حلقه for-each برای محاسبات
for (int value : values) {
    sum += value;           // محاسبه مجموع
    if (value > max) max = value; // پیدا کردن بزرگترین
    if (value < min) min = value; // پیدا کردن کوچکترین
}

// کست کردن به double برای دقت در محاسبه میانگین
double average = (double) sum / values.length;

IO.println("Array: " + Arrays.toString(values));
IO.println("Sum: " + sum);
IO.println("Average: " + average);
IO.println("Maximum: " + max);
IO.println("Minimum: " + min);
```

---

### ۲. محاسبه مجموع آرایه دوم

یک مثال ساده‌تر برای تمرین دوباره عملیات انباشت (Accumulation):

```Java
int[] moreNumbers = {45, 23, 67, 12, 89, 34};
int total = 0;

for (int num : moreNumbers) {
    total += num;
}

IO.println("");
IO.println("Second array: " + Arrays.toString(moreNumbers));
IO.println("Total of second array: " + total);
```

---

### چند نکته فنی در مورد کدهای بالا:

- **مقداردهی اولیه Max و Min:** شما هوشمندانه `max` و `min` را با `values[0]` مقداردهی کردید. این کار بسیار بهتر از مقداردهی با عدد صفر است، زیرا اگر تمام اعداد آرایه منفی باشند، عدد صفر نتیجه غلطی به شما می‌دهد.
    
- **متد `Arrays.toString()`:** استفاده از این متد راهی بسیار سریع و عالی برای چاپ محتویات آرایه در یک خط است، بدون اینکه نیاز به نوشتن حلقه دستی برای چاپ داشته باشید.
    
- **تبدیل نوع (Casting):** در محاسبه میانگین، استفاده از `(double)` ضروری است؛ در غیر این صورت جاوا تقسیم عدد صحیح انجام می‌دهد و بخش اعشاری نتیجه را حذف می‌کند.

## کپی کردن آرایه‌ها (Array Copying)

در جاوا برای کپی کردن داده‌ها از یک آرایه به آرایه دیگر، متد بسیار کارآمد `System.arraycopy()` وجود دارد. ساختار این متد به شرح زیر است:

`public static void arraycopy(Object src, int srcPos, Object dest, int destPos, int length)`

این متد ۵ پارامتر می‌گیرد:

1. **src**: آرایه مبدأ.
    
2. **srcPos**: موقعیت شروع در آرایه مبدأ (اندیس).
    
3. **dest**: آرایه مقصد.
    
4. **destPos**: موقعیت شروع در آرایه مقصد.
    
5. **length**: تعداد عناصری که باید کپی شوند.

---

## تمرینات کپی آرایه

#### ۱. کپی دستی و اثبات استقلال (Manual Copy)

زمانی که یک آرایه جدید با `new` می‌سازید و مقادیر را تک‌تک کپی می‌کنید، دو آرایه کاملاً مستقل در حافظه خواهید داشت. تغییر در یکی، دیگری را تغییر نمی‌دهد.

```Java
import java.util.Arrays;

int[] original = {1, 2, 3, 4, 5};
int[] copy = new int[original.length];

// کپی دستی با استفاده از حلقه
for (int i = 0; i < original.length; i++) {
    copy[i] = original[i];
}

IO.println("Original: " + Arrays.toString(original));
IO.println("Copy: " + Arrays.toString(copy));

// تغییر در کپی برای اثبات مستقل بودن
copy[0] = 999;
copy[4] = 777;

IO.println("\nAfter modifying the copy:");
IO.println("Original (بدون تغییر): " + Arrays.toString(original));
IO.println("Copy (تغییر یافته): " + Arrays.toString(copy));
```

#### ۲. کپی بهینه با `System.arraycopy`

این روش بسیار سریع‌تر از حلقه `for` است، مخصوصاً برای آرایه‌های بزرگ، چون مستقیماً در سطح حافظه عمل می‌کند.

```Java
int[] source = {10, 20, 30, 40, 50};
int[] destination = new int[5];

// کپی کل آرایه از اندیس 0 مبدأ به اندیس 0 مقصد
System.arraycopy(source, 0, destination, 0, source.length);

IO.println("\nUsing System.arraycopy:");
IO.println("Source: " + Arrays.toString(source));
IO.println("Destination: " + Arrays.toString(destination));
```

---

### کپی بخشی از آرایه (مثال انواع قهوه)

این متد به شما اجازه می‌دهد فقط قطعه‌ای (Subsequence) از یک آرایه را جدا کنید:

```Java
String[] copyFrom = {
    "Affogato", "Americano", "Cappuccino", "Corretto", "Cortado",
    "Doppio", "Espresso", "Frappucino", "Freddo", "Lungo", "Macchiato",
    "Marocchino", "Ristretto" };

String[] copyTo = new String[7];

// کپی 7 المان، شروع از اندیس 2 (Cappuccino)
System.arraycopy(copyFrom, 2, copyTo, 0, 7);

for (String coffee : copyTo) {
    IO.print(coffee + " ");
}
```

**چرا از این متد استفاده کنیم؟**

- **سرعت:** از حلقه‌های معمولی بسیار سریع‌تر است.
    
- **انعطاف:** می‌توانید بخشی از آرایه A را در وسط آرایه B کپی کنید.


## مدیریت و دستکاری آرایه‌ها (Array Manipulations)

آرایه‌ها یکی از قدرتمندترین ابزارها در برنامه‌نویسی هستند. جاوا برای تسهیل کار با آن‌ها، متدهای آماده‌ای را در کلاس `java.util.Arrays` و کلاس `System` قرار داده است. این متدها باعث می‌شوند به جای نوشتن حلقه‌های طولانی، بسیاری از کارها را در **یک خط کد** انجام دهید.

---

### کپی کردن با `Arrays.copyOfRange`

در مثال قبلی از `System.arraycopy` استفاده کردیم که نیاز داشت ابتدا آرایه مقصد را بسازیم. اما متد `Arrays.copyOfRange` این کار را ساده‌تر می‌کند، زیرا خودش آرایه جدید را ساخته و برمی‌گرداند:

```Java
class ArrayCopyOfDemo {
    public static void main(String[] args) {
        String[] copyFrom = {
            "Affogato", "Americano", "Cappuccino", "Corretto", "Cortado",
            "Doppio", "Espresso", "Frappucino", "Freddo", "Lungo", "Macchiato",
            "Marocchino", "Ristretto" };

        // کپی از اندیس ۲ (شامل خود آن) تا اندیس ۹ (بدون شامل شدن خود آن)
        String[] copyTo = Arrays.copyOfRange(copyFrom, 2, 9);
        
        for (String coffee : copyTo) {
            IO.print(coffee + " ");
        }
    }
}
```

**نکته مهم:** پارامتر دوم (شروع) **Inclusive** (شامل شونده) و پارامتر سوم (پایان) **Exclusive** (شامل نشونده) است. یعنی در مثال بالا، عنصر اندیس ۹ کپی نمی‌شود.

---

### متدهای کاربردی در کلاس `Arrays`

کلاس `Arrays` ابزارهای بسیار مفیدی برای وظایف رایج ارائه می‌دهد:

|**متد**|**کاربرد**|
|---|---|
|`binarySearch()`|جستجوی یک مقدار خاص در آرایه و برگرداندن اندیس آن (آرایه باید مرتب باشد).|
|`equals()`|مقایسه دو آرایه برای بررسی برابری محتویات آن‌ها.|
|`fill()`|پر کردن تمام خانه‌های آرایه با یک مقدار مشخص.|
|`sort()`|مرتب‌سازی آرایه به صورت صعودی.|
|`parallelSort()`|مرتب‌سازی موازی (سریع‌تر برای آرایه‌های بسیار بزرگ در سیستم‌های چند هسته‌ای).|
|`toString()`|تبدیل محتویات آرایه به یک رشته خوانا (مانند `[A, B, C]`).|

---

### استفاده از Stream و چاپ پیشرفته

در جاوا ۸ به بعد، می‌توانید از `stream()` برای کار روی آرایه‌ها استفاده کنید. این روش برای عملیات تجمعی بسیار مدرن و تمیز است:

```Java
// چاپ اعضای آرایه با استفاده از استریم
Arrays.stream(copyTo).map(coffee -> coffee + " ").forEach(IO::print);

// تبدیل مستقیم به رشته و چاپ (ساده‌ترین راه برای دیباگ)
IO.println(Arrays.toString(copyTo));
```

خروجی `Arrays.toString`:

`[Cappuccino, Corretto, Cortado, Doppio, Espresso, Frappucino, Freddo]`

---

### تمرین نهایی:

یک آرایه عدد صحیح تعریف کنید، آن را با `sort()` مرتب کنید، سپس با `binarySearch()` جایگاه یک عدد خاص را در آن پیدا کنید.

## جمع‌بندی: متغیرها و آرایه‌ها

در این بخش، مفاهیم کلیدی متغیرها و آرایه‌ها در زبان جاوا را مرور می‌کنیم.

#### ۱. انواع متغیرها از نظر دامنه (Scope)

زبان جاوا از اصطلاحات «فیلد» و «متغیر» برای توصیف محل ذخیره‌سازی داده‌ها استفاده می‌کند:

- **متغیرهای نمونه (Instance Variables):** فیلدهای غیر ایستا (`non-static`) که برای هر شیء (Instance) از کلاس منحصر‌به‌فرد هستند.
    
- **متغیرهای کلاس (Class Variables):** فیلدهایی که با کلمه کلیدی `static` تعریف می‌شوند؛ تنها یک نسخه از آن‌ها وجود دارد، فارغ از اینکه چند شیء از آن کلاس ساخته شده باشد.
    
- **متغیرهای محلی (Local Variables):** وضعیت موقت را داخل یک متد ذخیره می‌کنند.
    
- **پارامترها (Parameters):** متغیرهایی هستند که اطلاعات اضافی را به یک متد منتقل می‌کنند.


> **نکته:** متغیرهای محلی و پارامترها همیشه «متغیر» نامیده می‌شوند، نه «فیلد».

---

#### ۲. انواع داده‌های اولیه و مقادیر پیش‌فرض

هشت نوع داده اولیه وجود دارد که زیربنای جاوا را تشکیل می‌دهند:

- **اعداد صحیح:** `byte`, `short`, `int`, `long`
    
- **اعداد اعشاری:** `float`, `double`
    
- **منطقی:** `boolean`
    
- **کاراکتر:** `char`


کلاس `java.lang.String` برای رشته‌های متنی استفاده می‌شود.

- **فیلدها:** اگر مقداردهی نشوند، کامپایلر یک مقدار پیش‌فرض (مثل `0` یا `null`) به آن‌ها اختصاص می‌دهد.
    
- **متغیرهای محلی:** کامپایلر هیچ مقدار پیش‌فرضی به آن‌ها نمی‌دهد و باید قبل از استفاده، حتماً مقداردهی شوند.


---

#### ۳. لیترال‌ها و آرایه‌ها

- **لیترال (Literal):** نمایش مستقیم یک مقدار ثابت در کد سورس (مانند `true` یا `100`).
    
- **آرایه (Array):** یک شیء ظرف‌گونه که تعداد مشخصی از مقادیر را از **یک نوع واحد** نگه می‌دارد.
    
    - طول آرایه در زمان ایجاد (Creation) تعیین می‌شود.
        
    - پس از ایجاد، طول آرایه **ثابت** است و تغییر نمی‌کند.
