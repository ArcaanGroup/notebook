شما پیش از این آموختید که اشیاء وضعیت خود را در فیلدها ذخیره می‌کنند. با این حال، زبان برنامه‌نویسی جاوا از واژه **متغیر** (Variable) نیز استفاده می‌کند. این بخش به بررسی این رابطه، قوانین و قراردادهای نام‌گذاری متغیرها، انواع داده‌های اصلی (انواع اولیه یا Primitive، رشته‌های کاراکتری و آرایه‌ها)، مقادیر پیش‌فرض و مقادیر صریح (Literals) می‌پردازد.

## انواع اولیه (Primitive Types)

زبان برنامه‌نویسی جاوا دارای «تایپ استاتیک» (Statically-typed) است، به این معنی که تمام متغیرها باید پیش از استفاده، ابتدا تعریف شوند. این کار شامل اعلام نوع و نام متغیر است، همان‌طور که پیش‌تر مشاهده کردید:

`int gear = 1;`

انجام این کار به برنامه شما می‌گوید که فیلدی به نام `gear` وجود دارد، داده‌های عددی را نگه می‌دارد و مقدار اولیه آن ۱ است. نوع داده‌ی یک متغیر، مقادیری که می‌تواند داشته باشد و عملیاتی که می‌توان روی آن انجام داد را تعیین می‌کند. علاوه بر `int` ، زبان برنامه‌نویسی جاوا از هفت نوع داده اولیه دیگر نیز پشتیبانی می‌کند. یک نوع اولیه توسط زبان از پیش تعریف شده و با یک کلمه کلیدی رزرو شده نام‌گذاری می‌شود. مقادیر اولیه، وضعیت (State) خود را با سایر مقادیر اولیه به اشتراک نمی‌گذارند. هشت نوع داده اولیه پشتیبانی شده در جاوا عبارتند از:

- **byte:** نوع داده byte یک عدد صحیح ۸ بیتی علامت‌دار به روش مکمل دو (Two's complement) است. حداقل مقدار آن ۱۲۸- و حداکثر مقدار آن ۱۲۷ (شامل خود آن) است. نوع داده byte می‌تواند برای صرفه‌جویی در حافظه در آرایه‌های بزرگ، جایی که حفظ حافظه اهمیت دارد، مفید باشد. همچنین می‌توان از آن‌ها به جای `int` در جاهایی که محدودیت‌های آن‌ها به شفافیت کد کمک می‌کند، استفاده کرد؛ این واقعیت که محدوده یک متغیر محدود است، می‌تواند به عنوان نوعی مستندسازی عمل کند.
    
- **short:** نوع داده short یک عدد صحیح ۱۶ بیتی علامت‌دار به روش مکمل دو است. حداقل مقدار آن ۳۲,۷۶۸- و حداکثر مقدار آن ۳۲,۷۶۷ (شامل خود آن) است. مشابه `byte` ، همان دستورالعمل‌ها صدق می‌کنند: می‌توانید از `short` برای صرفه‌جویی در حافظه در آرایه‌های بزرگ استفاده کنید.
    
- **int:** به طور پیش‌فرض، نوع داده int یک عدد صحیح ۳۲ بیتی علامت‌دار به روش مکمل دو است که حداقل مقدار آن
    
    $$-2^{31}$$
    
    و حداکثر مقدار آن
    
    $$2^{31}-1$$
    
    می‌باشد.
    
- **long:** نوع داده long یک عدد صحیح ۶۴ بیتی مکمل دو است. مقدار حداقل آن
    
    $$-2^{63}$$
    
    و حداکثر آن
    
    $$2^{63}-1$$
    
    است.
    
- **float:** نوع داده float یک عدد اعشاری ۳۲ بیتی با دقت معمولی (Single-precision) مطابق استاندارد IEEE 754 است. همانند توصیه‌های مربوط به `byte` و `short` ، اگر نیاز به صرفه‌جویی در حافظه در آرایه‌های بزرگ از اعداد اعشاری دارید، از `float` (به جای `double`) استفاده کنید. این نوع داده هرگز نباید برای مقادیر دقیق، مانند ارز و پول، استفاده شود. برای آن منظور، باید از کلاس `java.math.BigDecimal` استفاده کنید.
    
- **double:** نوع داده double یک عدد اعشاری ۶۴ بیتی با دقت مضاعف (Double-precision) مطابق استاندارد IEEE 754 است. برای مقادیر اعشاری، این نوع داده معمولاً انتخاب پیش‌فرض است. همان‌طور که در بالا ذکر شد، این نوع داده هرگز نباید برای مقادیر دقیق استفاده شود.
    
- **boolean:** نوع داده boolean تنها دو مقدار ممکن دارد: `true` (درست) و `false` (نادرست). از این نوع داده برای پرچم‌های (Flags) ساده‌ای که شرایط درست/نادرست را ردیابی می‌کنند، استفاده کنید. این نوع داده نشان‌دهنده یک بیت اطلاعات است، اما «اندازه» آن به طور دقیق تعریف نشده است.
    
- **char:** نوع داده char یک کاراکتر واحد ۱۶ بیتی یونیکد (Unicode) است. حداقل مقدار آن `\u0000` (یا ۰) و حداکثر مقدار آن `\uffff` (یا ۶۵,۵۳۵ شامل خود آن) است.


توجه داشته باشید که در Java SE 8 و نسخه‌های جدیدتر، می‌توانید از نوع داده `int` برای نمایش یک عدد صحیح ۳۲ بیتی بدون علامت (Unsigned) استفاده کنید که حداقل مقدار آن ۰ و حداکثر مقدار آن

$$2^{32}-1$$

است. از کلاس `Integer` برای استفاده از `int` به عنوان عدد بدون علامت استفاده کنید. متدهای استاتیک مانند `Integer.compareUnsigned()` برای پشتیبانی از عملیات محاسباتی اعداد بدون علامت اضافه شده‌اند. به همین ترتیب، می‌توانید از `long` برای نمایش یک عدد ۶۴ بیتی بدون علامت استفاده کنید.

علاوه بر هشت نوع داده اولیه ذکر شده، زبان جاوا از طریق کلاس `java.lang.String` حمایت ویژه‌ای از رشته‌های کاراکتری (Character strings) ارائه می‌دهد. قرار دادن رشته کاراکتری خود در داخل گیومه (Double quotes) به طور خودکار یک شیء `String` جدید ایجاد می‌کند:

`String s = "this is a string";`

اشیاء `String` تغییرناپذیر (Immutable) هستند، به این معنی که پس از ایجاد، مقادیر آن‌ها قابل تغییر نیست. کلاس `String` از نظر فنی یک نوع داده اولیه نیست، اما با توجه به پشتیبانی ویژه‌ای که زبان به آن می‌دهد، احتمالاً تمایل خواهید داشت که آن را به عنوان یک نوع پایه در نظر بگیرید.

## مقداردهی اولیه به متغیر با مقادیر پیش‌فرض

همیشه لازم نیست هنگام تعریف یک فیلد، به آن مقدار اختصاص دهید. فیلدهایی که تعریف می‌شوند اما مقداردهی اولیه نمی‌شوند، توسط کامپایلر با یک مقدار پیش‌فرض منطقی تنظیم می‌گردند. به طور کلی، این مقدار پیش‌فرض بسته به نوع داده، صفر یا `null` خواهد بود. با این حال، تکیه بر این مقادیر پیش‌فرض معمولاً در برنامه‌نویسی **سبک مناسبی تلقی نمی‌شود**.

جدول زیر مقادیر پیش‌فرض را برای انواع داده‌های ذکر شده خلاصه می‌کند:

|**نوع داده (Data Type)**|**مقدار پیش‌فرض (برای فیلدها)**|
|---|---|
|`byte`|0|
|`short`|0|
|`int`|0|
|`long`|0L|
|`float`|0.0f|
|`double`|0.0d|
|`char`|`\u0000`|
|`String` (یا هر شیء دیگر)|null|
|`boolean`|false|

**متغیرهای محلی (Local Variables)** کمی متفاوت هستند؛ کامپایلر هرگز مقدار پیش‌فرضی به یک متغیر محلی مقداردهی نشده اختصاص نمی‌دهد. اگر نمی‌توانید متغیر محلی خود را در همان جایی که تعریف شده است مقداردهی کنید، حتماً پیش از آنکه بخواهید از آن استفاده کنید، مقداری به آن اختصاص دهید. تلاش برای دسترسی به یک متغیر محلی که مقداردهی اولیه نشده است، منجر به **خطای زمان کامپایل** (Compile-time error) خواهد شد.

## ایجاد مقادیر با استفاده از لیترال‌ها (Literals)

احتمالاً متوجه شده‌اید که هنگام مقداردهی اولیه به یک متغیر از نوع اولیه (Primitive)، از کلمه کلیدی `new` استفاده نمی‌شود. انواع اولیه، داده‌های خاصی هستند که در ذات زبان برنامه‌نویسی جاوا ساخته شده‌اند؛ آن‌ها اشیائی نیستند که از یک کلاس ساخته شده باشند.

یک **لیترال (Literal)**، نمایش یک مقدار ثابت در سورس‌کد است؛ لیترال‌ها مستقیماً در کد شما نوشته می‌شوند و نیاز به هیچ‌گونه محاسباتی ندارند. همان‌طور که در زیر نشان داده شده، می‌توان یک لیترال را به متغیری از نوع اولیه اختصاص داد:

```Java
boolean result = true;
char capitalC = 'C';
byte b = 100;
short s = 10000;
int i = 100000;
```

## لیترال‌های صحیح (Integer Literals)

یک لیترال صحیح در صورتی از نوع `long` محسوب می‌شود که به حرف `L` یا `l` ختم شود؛ در غیر این صورت از نوع `int` است. توصیه می‌شود همیشه از حرف بزرگ `L` استفاده کنید، زیرا تشخیص حرف کوچک `l` از عدد `1` دشوار است.

مقادیر انواع صحیح (`byte`, `short`, `int`, `long`) را می‌توان از لیترال‌های `int` ایجاد کرد. مقادیری از نوع `long` که از محدوده `int` فراتر می‌روند، باید با لیترال‌های `long` ایجاد شوند. لیترال‌های صحیح را می‌توان در این سیستم‌های عددی نمایش داد:

- **ده‌دهی (Decimal):** مبنای ۱۰، شامل ارقام ۰ تا ۹؛ این همان سیستم عددی است که هر روز استفاده می‌کنید.
    
- **شانزده‌دهی (Hexadecimal):** مبنای ۱۶، شامل ارقام ۰ تا ۹ و حروف A تا F.
    
- **دودویی (Binary):** مبنای ۲، شامل ارقام ۰ و ۱ (در Java SE 7 و نسخه‌های جدیدتر).


در برنامه‌نویسی عمومی، احتمالاً سیستم ده‌دهی تنها سیستمی است که استفاده خواهید کرد. اما اگر نیاز به سیستم‌های دیگر داشتید، مثال زیر نحوه‌ی صحیح نوشتن آن‌ها را نشان می‌دهد. پیشوند `0x` نشان‌دهنده شانزده‌دهی و `0b` نشان‌دهنده دودویی است:

```Java
// عدد ۲۶ در سیستم ده‌دهی
int decimalValue = 26;
// عدد ۲۶ در سیستم شانزده‌دهی
int hexadecimalValue = 0x1a;
// عدد ۲۶ در سیستم دودویی
int binaryValue = 0b11010;
```

## لیترال‌های اعشاری (Floating-Point Literals)

یک لیترال اعشاری در صورتی از نوع `float` است که به حرف `F` یا `f` ختم شود؛ در غیر این صورت، نوع آن `double` است (که می‌توان به صورت اختیاری از `D` یا `d` نیز در انتهای آن استفاده کرد).

انواع اعشاری را می‌توان با استفاده از این موارد نمایش داد:

- **E یا e:** برای نماد علمی (Scientific Notation).
    
- **F یا f:** لیترال ۳۲ بیتی از نوع `float`.
    
- **D یا d:** لیترال ۶۴ بیتی از نوع `double` (این مورد پیش‌فرض است و طبق قرارداد معمولاً حذف می‌شود).


```Java
double d1 = 123.4;
// مقداری مشابه d1، اما با نماد علمی
double d2 = 1.234e2;
float f1  = 123.4f;
```

## لیترال‌های کاراکتری و رشته‌ای

لیترال‌های نوع `char` و `String` می‌توانند شامل هر کاراکتر یونیکد (UTF-16) باشند. اگر ویرایشگر و سیستم‌فایل شما اجازه دهد، می‌توانید مستقیماً از این کاراکترها در کد استفاده کنید. در غیر این صورت، می‌توانید از **Escape Sequenceهای یونیکد** مانند `\u0108` استفاده کنید.

- همیشه برای لیترال‌های **char** از **تک-کویتیشن** (`' '`) استفاده کنید.
    
- همیشه برای لیترال‌های **String** از **دابل-کویتیشن** (`" "`) استفاده کنید.


جاوا همچنین از سکانس‌های فرار (Escape Sequences) خاصی پشتیبانی می‌کند:

|**سکانس**|**توصیف**|
|---|---|
|`\b`|Backspace (پاک کردن کاراکتر قبل)|
|`\t`|Tab (فاصله‌گذاری افقی)|
|`\n`|Line feed (رفتن به خط بعد)|
|`\f`|Form feed|
|`\r`|Carriage return|
|`\"`|Double quote|
|`\'`|Single quote|
|`\\`|Backslash|


## لیترال‌های خاص: null و class

- **لیترال null:** یک مقدار خاص است که می‌تواند به هر **نوع ارجاعی** (Reference type) اختصاص یابد. از `null` نمی‌توان برای متغیرهای نوع اولیه (Primitive) استفاده کرد. معمولاً در برنامه‌ها از آن به عنوان نشانه‌ای برای در دسترس نبودن یک شیء استفاده می‌شود.
    
- **لیترال کلاس (class literal):** با اضافه کردن `.class` به نام یک تایپ ایجاد می‌شود (مثلاً `String.class`). این لیترال به شیئی اشاره دارد که خودِ آن تایپ را در جاوا نمایندگی می‌کند.


## استفاده از کاراکتر زیرخط (Underscore) در لیترال‌های عددی

در Java SE 7 و نسخه‌های جدیدتر، می‌توانید از هر تعداد کاراکتر زیرخط (`_`) در هر جایی بین ارقام در یک لیترال عددی استفاده کنید. این قابلیت به شما اجازه می‌دهد تا گروه‌هایی از ارقام را از هم جدا کنید که باعث **بهبود خوانایی** کد می‌شود.

برای مثال، اگر کد شما شامل اعدادی با ارقام زیاد است، می‌توانید از زیرخط برای جدا کردن دسته‌های سه‌تایی استفاده کنید؛ مشابه کاری که در دنیای واقعی با کاما (`,`) یا فاصله انجام می‌دهید.

در مثال زیر، روش‌های مختلف استفاده از زیرخط در لیترال‌های عددی نشان داده شده است:

```Java
long creditCardNumber = 1234_5678_9012_3456L;
long socialSecurityNumber = 999_99_9999L;
float pi =  3.14_15F;
long hexBytes = 0xFF_EC_DE_5E;
long hexWords = 0xCAFE_BABE;
long maxLong = 0x7fff_ffff_ffff_ffffL;
byte nybbles = 0b0010_0101;
long bytes = 0b11010010_01101001_10010100_10010010;
```

## محدودیت‌های قرارگیری زیرخط

شما فقط می‌توانید زیرخط را **بین ارقام** قرار دهید. قرار دادن زیرخط در مکان‌های زیر **غیرمجاز** است:

- در ابتدا یا انتهای یک عدد
    
- در کنار نقطه اعشار در لیترال‌های اعشاری
    
- قبل از پسوندهای `F` (برای float) یا `L` (برای long)
    
- در موقعیت‌هایی که انتظار می‌رود یک رشته از ارقام وجود داشته باشد (مانند داخل پیشوندهای `0x` یا `0b`)


مثال‌های زیر موارد معتبر و نامعتبر را نشان می‌دهند:

```Java
// نامعتبر: قرار گرفتن در کنار نقطه اعشار
float pi1 = 3_.1415F; 
float pi2 = 3._1415F; 

// نامعتبر: قرار گرفتن قبل از پسوند L
long socialSecurityNumber1 = 999_99_9999_L; 

// معتبر (لیترال ده‌دهی)
int x1 = 5_2; 

// نامعتبر: قرار گرفتن در انتهای لیترال
int x2 = 52_; 

// معتبر (می‌توان بیش از یک زیرخط استفاده کرد)
int x3 = 5_______2; 

// نامعتبر: قرار گرفتن داخل پیشوند 0x
int x4 = 0_x52; 

// نامعتبر: قرار گرفتن در ابتدای عدد (بعد از پیشوند)
int x5 = 0x_52; 

// معتبر (لیترال شانزده‌دهی)
int x6 = 0x5_2; 

// نامعتبر: قرار گرفتن در انتهای عدد
int x7 = 0x52_; 
```
