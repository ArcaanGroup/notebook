#### استفاده از دستورات Switch برای کنترل جریان برنامه

دستور `switch` یکی از پنج دستور کنترل جریان موجود در زبان جاوا است. این دستور امکان وجود هر تعداد مسیر اجرا را فراهم می‌کند. یک دستور `switch` یک **متغیر انتخاب‌گر** (selector variable) را به عنوان آرگومان می‌پذیرد و از مقدار این متغیر برای انتخاب مسیری که اجرا خواهد شد، استفاده می‌کند.

شما باید نوع متغیر انتخاب‌گر خود را از میان انواع زیر انتخاب کنید:

- انواع داده‌های اولیه: `byte`, `short`, `char`, و `int`
    
- انواع بسته‌بندی‌کننده (Wrapper types): `Character`, `Byte`, `Short`, و `Integer`
    
- انواع شمارشی (enumerated types)
    
- نوع `String`

شایان ذکر است که از انواع اولیه زیر **نمی‌توان** برای نوع متغیر انتخاب‌گر استفاده کرد: `boolean`, `long`, `float`, و `double`.

بیایید اولین مثال از یک دستور `switch` را ببینیم:

```Java
int quarter = ...; // هر مقداری
String quarterLabel = null;

switch (quarter) {
    case 0: quarterLabel = "Q1 - Winter"; 
            break;
    case 1: quarterLabel = "Q2 - Spring"; 
            break;
    case 2: quarterLabel = "Q3 - Summer"; 
            break;
    case 3: quarterLabel = "Q4 - Autumn"; 
            break;
    default: quarterLabel = "Unknown quarter";
};
```

بدنه یک دستور `switch` با نام **بلاک switch** شناخته می‌شود. یک دستور در بلاک switch می‌تواند با یک یا چند برچسب `case` یا `default` نشانه‌گذاری شود. دستور `switch` عبارت خود را ارزیابی کرده و سپس تمام دستوراتی را که پس از برچسب `case` مطابقت‌یافته می‌آیند، اجرا می‌کند.

شاید متوجه استفاده از کلمه کلیدی `break` شده باشید. هر دستور `break` به دستور `switch` دربرگیرنده خاتمه می‌دهد. جریان کنترل با اولین دستور پس از بلاک switch ادامه می‌یابد. دستورات `break` ضروری هستند، زیرا بدون آن‌ها، دستورات در بلاک‌های switch دچار **ریزش** (fall through) می‌شوند. تمام دستورات پس از برچسب `case` مطابقت‌یافته، بدون توجه به عبارتِ برچسب‌های `case` بعدی، به ترتیب اجرا می‌شوند تا زمانی که یک دستور `break` مشاهده شود.

کد زیر از خاصیت "fall through" برای پر کردن لیست `futureMonths` استفاده می‌کند:

```Java
int month = 8;
List<String> futureMonths = new ArrayList<>();
switch (month) {
    case 1:  futureMonths.add("January");
    case 2:  futureMonths.add("February");
    case 3:  futureMonths.add("March");
    case 4:  futureMonths.add("April");
    case 5:  futureMonths.add("May");
    case 6:  futureMonths.add("June");
    case 7:  futureMonths.add("July");
    case 8:  futureMonths.add("August");
    case 9:  futureMonths.add("September");
    case 10: futureMonths.add("October");
    case 11: futureMonths.add("November");
    case 12: futureMonths.add("December");
             break;
    default: break;
}
```

از نظر فنی، آخرین `break` مورد نیاز نیست زیرا جریان از دستور `switch` خارج می‌شود. با این حال استفاده از `break` توصیه می‌شود تا تغییر دادن کد آسان‌تر و کمتر مستعد خطا باشد. بخش `default` تمام مقادیری را که به طور صریح توسط یکی از بخش‌های `case` مدیریت نشده‌اند، کنترل می‌کند.

مثال کد زیر نشان می‌دهد که چگونه یک دستور می‌تواند چندین برچسب `case` داشته باشد. این کد تعداد روزهای یک ماه خاص را محاسبه می‌کند:

```Java
int month = 2;
int year = 2021;
int numDays = 0;

switch (month) {
    case 1: case 3: case 5:   // ژانویه مارس می
    case 7: case 8: case 10:  // جولای آگوست اکتبر
    case 12:
        numDays = 31;
        break;
    case 4: case 6:           // آوریل ژوئن
    case 9: case 11:          // سپتامبر نوامبر
        numDays = 30;
        break;
    case 2: // فوریه
        if (((year % 4 == 0) && 
             !(year % 100 == 0))
             || (year % 400 == 0))
            numDays = 29;
        else
            numDays = 28;
        break;
    default:
        IO.println("Invalid month.");
        break;
}
```

این کد برای بیش از یک `case` دارای یک دستور واحد است.

### انتخاب بین دستورات Switch و If-then-else

تصمیم‌گیری برای استفاده از دستورات `if-then-else` یا دستور `switch` بر اساس خوانایی و عبارتی است که دستور در حال تست کردن آن است. یک دستور `if-then-else` می‌تواند عبارات را بر اساس محدوده‌ای از مقادیر یا شرایط تست کند، در حالی که یک دستور `switch` عبارات را تنها بر اساس یک عدد صحیح واحد، مقدار شمارشی (enumerated) یا یک شیء `String` تست می‌کند.

برای مثال، کد زیر می‌تواند با یک دستور `switch` نوشته شود:

```Java
int month = ...; // هر ماهی
if (month == 1) {
    IO.println("January");
} else if (month == 2) {
    IO.println("February");
} ... // و به همین ترتیب
```

از سوی دیگر، کد زیر را نمی‌توان با یک دستور `switch` نوشت، زیرا دستورات `switch` از برچسب‌هایی از نوع `boolean` پشتیبانی نمی‌کنند:

```Java
int temperature = ...; // هر دمایی
if (temperature < 0) {
    IO.println("Water is ice");
} else if (temperature < 100){
    IO.println("Water is liquid, known as water");
} else {
    IO.println("Water is vapor");
}
```

### استفاده از String به عنوان نوعی برای برچسب‌های Case

در Java SE 7 و نسخه‌های جدیدتر، می‌توانید از یک شیء `String` در عبارت دستور `switch` استفاده کنید. مثال کد زیر، شماره ماه را بر اساس مقدار رشته‌ای به نام `month` نمایش می‌دهد:

```Java
String month = ...; // هر ماهی
int monthNumber = -1;

switch (month.toLowerCase()) {
    case "january":
        monthNumber = 1;
        break;
    case "february":
        monthNumber = 2;
        break;
    case "march":
        monthNumber = 3;
        break;
    case "april":
        monthNumber = 4;
        break;
    case "may":
        monthNumber = 5;
        break;
    case "june":
        monthNumber = 6;
        break;
    case "july":
        monthNumber = 7;
        break;
    case "august":
        monthNumber = 8;
        break;
    case "september":
        monthNumber = 9;
        break;
    case "october":
        monthNumber = 10;
        break;
    case "november":
        monthNumber = 11;
        break;
    case "december":
        monthNumber = 12;
        break;
    default: 
        monthNumber = 0;
        break;
}
```

رشته در عبارت `switch` با عبارات مرتبط با هر برچسب `case` مقایسه می‌شود، گویی که از متد `String.equals()` استفاده شده است. برای اینکه این مثال هر ماهی را بدون توجه به بزرگی یا کوچکی حروف بپذیرد، متغیر `month` (با متد `toLowerCase()`) به حروف کوچک تبدیل شده است و تمام رشته‌های مرتبط با برچسب‌های `case` نیز با حروف کوچک نوشته شده‌اند.

### متغیرهای انتخاب‌گر Null

متغیر انتخاب‌گر (selector variable) یک دستور `switch` می‌تواند یک شیء باشد، بنابراین این شیء می‌تواند `null` باشد. شما باید از کد خود در برابر متغیرهای انتخاب‌گر `null` محافظت کنید، زیرا در این صورت دستور `switch` خطای `NullPointerException` را پرتاب (throw) خواهد کرد.
