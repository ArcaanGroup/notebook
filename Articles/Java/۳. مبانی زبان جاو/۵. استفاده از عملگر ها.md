## عملگرها (Operators)

حالا که یاد گرفته‌اید چگونه متغیرها را تعریف و مقداردهی اولیه کنید، احتمالاً می‌خواهید بدانید چگونه با آن‌ها کاری انجام دهید. یادگیری عملگرهای زبان برنامه‌نویسی جاوا مکان خوبی برای شروع است. عملگرها نمادهای خاصی هستند که عملیات مشخصی را روی یک، دو یا سه عملوند انجام می‌دهند و سپس نتیجه‌ای را برمی‌گردانند.

همان‌طور که عملگرهای زبان برنامه‌نویسی جاوا را بررسی می‌کنیم، ممکن است دانستن پیشاپیش اینکه کدام عملگرها بالاترین اولویت را دارند برای شما مفید باشد. عملگرها در جدول زیر بر اساس ترتیب اولویت لیست شده‌اند. هرچه یک عملگر به بالای جدول نزدیک‌تر باشد، اولویت آن بالاتر است. عملگرهای با اولویت بالاتر، قبل از عملگرهای با اولویت نسبتاً پایین‌تر ارزیابی می‌شوند. عملگرهای موجود در یک خط دارای اولویت یکسان هستند. وقتی عملگرهایی با اولویت یکسان در یک عبارت ظاهر می‌شوند، یک قانون باید تعیین کند که کدام‌یک ابتدا ارزیابی شود. تمام عملگرهای دوتایی (binary) به جز عملگرهای انتسابی (assignment)، از چپ به راست ارزیابی می‌شوند؛ عملگرهای انتسابی از راست به چپ ارزیابی می‌شوند.

|**عملگرها**|**اولویت**|
|---|---|
|**پسوندی (postfix)**|`expr++` `expr--`|
|**یکانی (unary)**|`++expr` `--expr` `+expr` `-expr` `~` `!`|
|**ضرب‌ و تقسیم (multiplicative)**|`*` `/` `%`|
|**جمعی (additive)**|`+` `-`|
|**تغییر مکان (shift)**|`<<` `>>` `>>>`|
|**رابطه‌ای (relational)**|`<` `>` `<=` `>=` `instanceof`|
|**تساوی (equality)**|`==` `!=`|
|**AND بیتی**|`&`|
|**OR انحصاری بیتی**|`^`|
|**OR شامل‌شونده بیتی**|`|
|**AND منطقی**|`&&`|
|**OR منطقی**|`|
|**شرطی (ternary)**|`? :`|
|**انتسابی (assignment)**|`=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `|

در برنامه‌نویسی با اهداف عمومی، برخی عملگرها بیشتر از بقیه ظاهر می‌شوند؛ برای مثال، عملگر انتسابی `=` بسیار رایج‌تر از عملگر تغییر مکان راست بدون علامت `>>>` است. با در نظر گرفتن این موضوع، بحث زیر ابتدا بر عملگرهایی تمرکز می‌کند که به احتمال زیاد به طور منظم از آن‌ها استفاده خواهید کرد و در انتها بر عملگرهایی تمرکز می‌کند که کمتر رایج هستند. هر بحث با کد نمونه همراه است که می‌توانید آن را کامپایل و اجرا کنید. مطالعه خروجی آن به تقویت آنچه آموخته‌اید کمک می‌کند.

## عملگر انتسابی ساده

یکی از رایج‌ترین عملگرهایی که با آن مواجه خواهید شد، عملگر انتسابی ساده `=` است. شما این عملگر را در کلاس `Bicycle` مشاهده کردید؛ این عملگر مقدار سمت راست خود را به عملوند سمت چپ خود نسبت می‌دهد:

```Java
int cadence = 0;
int speed = 0;
int gear = 1;
```

این عملگر همچنین می‌تواند بر روی اشیاء برای تخصیص مراجع شیء (Object References) استفاده شود، همان‌طور که در بخش «ایجاد اشیاء» بحث شد.

### عملگرهای محاسباتی

زبان برنامه‌نویسی جاوا عملگرهایی را برای انجام جمع، تفریق، ضرب و تقسیم ارائه می‌دهد. احتمال زیادی وجود دارد که آن‌ها را از طریق معادل‌هایشان در ریاضیات پایه بشناسید. تنها نمادی که ممکن است برای شما جدید به نظر برسد `%` است که یک عملوند را بر دیگری تقسیم کرده و **باقیمانده** را به عنوان نتیجه برمی‌گرداند.

|**عملگر**|**توصیف**|
|---|---|
|`+`|عملگر جمع (همچنین برای اتصال رشته‌ها استفاده می‌شود)|
|`-`|عملگر تفریق|
|`*`|عملگر ضرب|
|`/`|عملگر تقسیم|
|`%`|عملگر باقیمانده|

برنامه زیر، `ArithmeticDemo` ، عملگرهای محاسباتی را آزمایش می‌کند:

```Java
class ArithmeticDemo {

    public static void main (String[] args) {

        int result = 1 + 2;
        // نتیجه اکنون 3 است
        IO.println("1 + 2 = " + result);
        int original_result = result;

        result = result - 1;
        // نتیجه اکنون 2 است
        IO.println(original_result + " - 1 = " + result);
        original_result = result;

        result = result * 2;
        // نتیجه اکنون 4 است
        IO.println(original_result + " * 2 = " + result);
        original_result = result;

        result = result / 2;
        // نتیجه اکنون 2 است
        IO.println(original_result + " / 2 = " + result);
        original_result = result;

        result = result + 8;
        // نتیجه اکنون 10 است
        IO.println(original_result + " + 8 = " + result);
        original_result = result;

        result = result % 7;
        // نتیجه اکنون 3 است
        IO.println(original_result + " % 7 = " + result);
    }
}
```

خروجی این برنامه به شرح زیر است:

```
1 + 2 = 3
3 - 1 = 2
2 * 2 = 4
4 / 2 = 2
2 + 8 = 10
10 % 7 = 3
```

شما همچنین می‌توانید عملگرهای محاسباتی را با عملگر انتسابی ساده ترکیب کنید تا **انتساب‌های مرکب** (Compound Assignments) ایجاد کنید. به عنوان مثال، `x += 1;` و `x = x + 1;` هر دو مقدار `x` را یک واحد افزایش می‌دهند.

عملگر `+` همچنین می‌تواند برای اتصال (Concatenating) دو رشته به یکدیگر استفاده شود، همان‌طور که در برنامه `ConcatDemo` نشان داده شده است:

```Java
class ConcatDemo {
    public static void main(String[] args){
        String firstString = "This is";
        String secondString = " a concatenated string.";
        String thirdString = firstString + secondString;
        IO.println(thirdString);
    }
}
```

در پایان این برنامه، متغیر `thirdString` حاوی عبارت `This is a concatenated string.` است که در خروجی استاندارد چاپ می‌شود.

## عملگرهای یکانی (Unary Operators)

عملگرهای یکانی تنها به یک عملوند نیاز دارند؛ آن‌ها عملیات‌های مختلفی مانند افزایش یا کاهش مقدار به اندازه یک واحد، منفی کردن یک عبارت یا معکوس کردن مقدار یک متغیر منطقی (boolean) را انجام می‌دهند.

|**عملگر**|**توصیف**|
|---|---|
|`+`|عملگر مثبت یکانی؛ نشان‌دهنده مقدار مثبت است (اعداد بدون این هم مثبت هستند).|
|`-`|عملگر منفی یکانی؛ یک عبارت را منفی می‌کند.|
|`++`|عملگر افزایش؛ مقدار را ۱ واحد افزایش می‌دهد.|
|`--`|عملگر کاهش؛ مقدار را ۱ واحد کاهش می‌دهد.|
|`!`|عملگر مکمل منطقی؛ مقدار یک boolean را معکوس می‌کند.|

برنامه زیر با نام `UnaryDemo` عملگرهای یکانی را آزمایش می‌کند:

```Java
class UnaryDemo {

    public static void main(String[] args) {

        int result = +1;
        // نتیجه اکنون 1 است
        IO.println(result);

        result--;
        // نتیجه اکنون 0 است
        IO.println(result);

        result++;
        // نتیجه اکنون 1 است
        IO.println(result);

        result = -result;
        // نتیجه اکنون -1 است
        IO.println(result);

        boolean success = false;
        // false
        IO.println(success);
        // true
        IO.println(!success);
    }
}
```

### تفاوت پیشوندی و پسوندی (Prefix vs Postfix)

عملگرهای افزایش/کاهش می‌توانند قبل از عملوند (**پیشوندی**) یا بعد از آن (**پسوندی**) قرار گیرند. کدهای `result++;` و `++result;` هر دو در نهایت منجر به افزایش یک واحدی مقدار `result` می‌شوند.

تنها تفاوت این است که:

- در نسخه پیشوندی (`++result`)، ابتدا مقدار افزایش یافته و سپس عبارت **با مقدار جدید** ارزیابی می‌شود.
    
- در نسخه پسوندی (`result++`)، ابتدا عبارت **با مقدار اصلی (قبلی)** ارزیابی شده و سپس مقدار افزایش می‌یابد.

اگر فقط یک افزایش ساده انجام می‌دهید، فرقی نمی‌کند کدام را انتخاب کنید. اما اگر از این عملگر در بخشی از یک عبارت بزرگتر استفاده می‌کنید، انتخابتان تفاوت قابل توجهی ایجاد خواهد کرد.

برنامه زیر با نام `PrePostDemo` تفاوت این دو حالت را نشان می‌دهد:

```Java
class PrePostDemo {
    public static void main(String[] args){
        int i = 3;
        i++;
        // عدد 4 را چاپ می‌کند
        IO.println(i);
        ++i;               
        // عدد 5 را چاپ می‌کند
        IO.println(i);
        // ابتدا افزایش می‌دهد، سپس چاپ می‌کند: عدد 6
        IO.println(++i);
        // ابتدا مقدار (6) را برای چاپ می‌فرستد، سپس افزایش می‌دهد: عدد 6
        IO.println(i++);
        // حالا مقدار نهایی را نشان می‌دهد: عدد 7
        IO.println(i);
    }
}
```


## عملگرهای رابطه‌ای و تساوی (Equality and Relational Operators)

عملگرهای تساوی و رابطه‌ای تعیین می‌کنند که آیا یک عملوند بزرگتر، کوچکتر، مساوی یا نامساوی با عملوند دیگر است. اکثر این عملگرها احتمالاً برای شما آشنا هستند. به خاطر داشته باشید که هنگام تست کردن برابری دو مقدار اولیه (Primitive)، حتماً باید از `==` استفاده کنید و نه از `=`.

|**عملگر**|**توصیف**|
|---|---|
|`==`|مساوی با|
|`!=`|نامساوی با|
|`>`|بزرگتر از|
|`>=`|بزرگتر یا مساوی با|
|`<`|کوچکتر از|
|`<=`|کوچکتر یا مساوی با|

برنامه زیر با نام `ComparisonDemo` عملگرهای مقایسه‌ای را آزمایش می‌کند:

```Java
class ComparisonDemo {

    public static void main(String[] args){
        int value1 = 1;
        int value2 = 2;
        if(value1 == value2)
            IO.println("value1 == value2");
        if(value1 != value2)
            IO.println("value1 != value2");
        if(value1 > value2)
            IO.println("value1 > value2");
        if(value1 < value2)
            IO.println("value1 < value2");
        if(value1 <= value2)
            IO.println("value1 <= value2");
    }
}
```

**خروجی این برنامه:**

```
value1 != value2
value1 <  value2
value1 <= value2
```

### عملگرهای شرطی (Conditional Operators)

عملگرهای `&&` و `||` عملیات **AND شرطی** و **OR شرطی** را روی دو عبارت منطقی (boolean) انجام می‌دهند. این عملگرها رفتار **"اتصال کوتاه" (short-circuiting)** دارند؛ به این معنی که عملوند دوم تنها در صورت نیاز ارزیابی می‌شود.

| **عملگر** | **توصیف**                                        |
| --------- | ------------------------------------------------ |
| `&&`      | AND شرطی (اگر اولی غلط باشد، دومی بررسی نمی‌شود) |
| `         |                                                  |

مثال زیر در برنامه `ConditionalDemo1` این عملگرها را تست می‌کند:

```Java
class ConditionalDemo1 {

    public static void main(String[] args){
        int value1 = 1;
        int value2 = 2;
        if ((value1 == 1) && (value2 == 2))
            IO.println("value1 is 1 AND value2 is 2");
        if ((value1 == 1) || (value2 == 1))
            IO.println("value1 is 1 OR value2 is 1");
    }
}
```

#### عملگر سه تایی (Ternary Operator)

عملگر شرطی دیگر `?:` است که می‌توان آن را به عنوان میان‌بری برای دستور `if-then-else` در نظر گرفت. این عملگر به این دلیل **سه‌تایی** نامیده می‌شود که از سه عملوند استفاده می‌کند.

در مثال زیر، این عملگر این‌گونه خوانده می‌شود: "اگر `someCondition` درست است، مقدار `value1` را به `result` اختصاص بده. در غیر این صورت، مقدار `value2` را به آن اختصاص بده."

```Java
class ConditionalDemo2 {

    public static void main(String[] args){
        int value1 = 1;
        int value2 = 2;
        int result;
        boolean someCondition = true;
        result = someCondition ? value1 : value2;

        IO.println(result);
    }
}
```

از آنجایی که `someCondition` مقدار `true` دارد، برنامه عدد "1" را چاپ می‌کند. زمانی از عملگر `?:` استفاده کنید که باعث خوانایی بیشتر کد شود؛ مثلاً وقتی عبارت‌ها کوتاه هستند و عوارض جانبی (مانند مقداردهی‌های پیچیده) ندارند.

## عملگر مقایسه نوع `instanceof`

عملگر `instanceof` یک شیء را با یک نوع مشخص مقایسه می‌کند. شما می‌توانید از آن برای تست این موضوع استفاده کنید که آیا یک شیء، نمونه‌ای (instance) از یک کلاس، نمونه‌ای از یک زیرکلاس، و یا نمونه‌ای از کلاسی است که یک رابط (interface) خاص را پیاده‌سازی کرده است یا خیر.

برنامه زیر با نام `InstanceofDemo` یک کلاس والد (`Parent`)، یک رابط ساده (`MyInterface`) و یک کلاس فرزند (`Child`) را تعریف می‌کند که از والد ارث‌بری کرده و رابط را پیاده‌سازی می‌کند.

```Java
class InstanceofDemo {
    public static void main(String[] args) {

        Parent obj1 = new Parent();
        Parent obj2 = new Child();

        IO.println("obj1 instanceof Parent: "
            + (obj1 instanceof Parent));
        IO.println("obj1 instanceof Child: "
            + (obj1 instanceof Child));
        IO.println("obj1 instanceof MyInterface: "
            + (obj1 instanceof MyInterface));
            
        IO.println("obj2 instanceof Parent: "
            + (obj2 instanceof Parent));
        IO.println("obj2 instanceof Child: "
            + (obj2 instanceof Child));
        IO.println("obj2 instanceof MyInterface: "
            + (obj2 instanceof MyInterface));
    }
}

class Parent {}
class Child extends Parent implements MyInterface {}
interface MyInterface {}
```

**خروجی این برنامه به شرح زیر است:**

```
obj1 instanceof Parent: true
obj1 instanceof Child: false
obj1 instanceof MyInterface: false
obj2 instanceof Parent: true
obj2 instanceof Child: true
obj2 instanceof MyInterface: true
```

#### یک نکته مهم:

هنگام استفاده از عملگر `instanceof` به خاطر داشته باشید که مقدار `null` نمونه‌ای از هیچ‌چیز نیست. بنابراین عبارت `null instanceof Object` همیشه مقدار `false` را برمی‌گرداند.

## عملگرهای بیتی و شیفت (Bitwise and Bit Shift Operators)

زبان برنامه‌نویسی جاوا عملگرهایی را برای انجام عملیات بیتی و شیفت روی انواع داده‌های صحیح (Integral types) ارائه می‌دهد. عملگرهایی که در این بخش مورد بحث قرار می‌گیرند، کمتر مورد استفاده قرار می‌گیرند؛ بنابراین، پوشش آن‌ها کوتاه است و هدف صرفاً آگاه کردن شما از وجود این عملگرهاست.

#### عملگرهای بیتی یکانی و دودویی

- **مکمل بیتی یکانی (`~`):** این عملگر الگوی بیتی را معکوس می‌کند؛ یعنی هر "0" را به "1" و هر "1" را به "0" تبدیل می‌کند. برای مثال، یک `byte` شامل ۸ بیت است؛ اعمال این عملگر روی مقداری با الگوی بیتی `00000000` آن را به `11111111` تغییر می‌دهد.
    
- **عملگر `&`:** عملیات **AND بیتی** را انجام می‌دهد.
    
- **عملگر `^`:** عملیات **OR انحصاری بیتی (XOR)** را انجام می‌دهد.
    
- **عملگر `|`:** عملیات **OR شامل‌شونده بیتی** را انجام می‌دهد.

#### عملگرهای شیفت (Shift Operators)

- **شیفت چپ علامت‌دار (`<<`):** الگوی بیتی را به سمت چپ حرکت می‌دهد.
    
- **شیفت راست علامت‌دار (`>>`):** الگوی بیتی را به سمت راست حرکت می‌دهد. در این حالت، الگوی بیتی توسط عملوند سمت چپ و تعداد جایگاه‌های شیفت توسط عملوند سمت راست تعیین می‌شود.
    
- **شیفت راست بدون علامت (`>>>`):** یک صفر را به داخلی‌ترین جایگاه سمت چپ (بیت علامت) وارد می‌کند، در حالی که در `>>` جایگاه سمت چپ به "توسعه علامت" (Sign Extension) بستگی دارد.    

برنامه زیر با نام `BitDemo` از عملگر AND بیتی استفاده می‌کند تا عدد "2" را در خروجی استاندارد چاپ کند:

```Java
class BitDemo {
    public static void main(String[] args) {
        int bitmask = 0x000F; // الگوی بیتی: 0000000000001111
        int val = 0x2222;     // الگوی بیتی: 0010001000100010
        // عدد "2" را چاپ می‌کند
        IO.println(val & bitmask);
    }
}
```

در این مثال، `0x000F` به عنوان یک «ماسک» عمل می‌کند که تنها ۴ بیت آخر `val` را نگه داشته و بقیه را صفر می‌کند.
