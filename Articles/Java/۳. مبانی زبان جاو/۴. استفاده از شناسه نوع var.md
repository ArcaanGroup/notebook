از نسخه **Java SE 10** به بعد، می‌توانید از کلمه کلیدی `var` برای تعریف **متغیرهای محلی** استفاده کنید. با این کار، شما به کامپایلر اجازه می‌دهید که خودش بر اساس مقداری که به متغیر می‌دهید، نوع واقعی آن را تشخیص دهد. نکته مهم این است که وقتی نوع متغیر مشخص شد، دیگر **قابل تغییر نیست**.

به مثال زیر توجه کنید:

```Java
String message = "Hello world!";
Path path = Path.of("debug.log");
InputStream stream = Files.newInputStream(path);
```

در اینجا نوشتن نوع دقیق متغیرها کمی تکراری و طولانی به نظر می‌رسد. با استفاده از `var` می‌توان کد بالا را به این شکل ساده کرد:

```Java
var message = "Hello world!";
var path = Path.of("debug.log");
var stream = Files.newInputStream(path);
```

---

### مثال‌های کاربردی از `var`

استفاده از `var` باعث می‌شود کد شما خلوت‌تر و خواناتر شود. در مثال زیر، متغیر `list` از نوع `List<String>` و متغیر `element` از نوع `String` تشخیص داده می‌شوند:

```Java
var list = List.of("one", "two", "three", "four");
for (var element : list) {
    IO.println(element);
}
```

همچنین می‌توانید از `var` در دستورات `try-with-resources` نیز استفاده کنید:

```Java
var path = Path.of("debug.log");
try (var stream = Files.newInputStream(path)) {
    // پردازش فایل
}
```

---

### محدودیت‌های استفاده از `var`

با وجود کاربردی بودن، محدودیت‌های مهمی برای استفاده از `var` وجود دارد که باید رعایت کنید:

1. **فقط برای متغیرهای محلی:** تنها در داخل متدها، سازنده‌ها (Constructors) و بلاک‌های مقداردهی اولیه مجاز است.
    
2. **عدم استفاده در فیلدها و پارامترها:** نمی‌توانید از `var` برای متغیرهای کلاس (Fields) یا پارامترهای ورودی متد استفاده کنید.
    
3. **الزام به مقداردهی آنی:** کامپایلر باید در همان لحظه تعریف متغیر، نوع آن را تشخیص دهد. بنابراین نمی‌توانید متغیری را با `var` تعریف کنید ولی به آن مقدار ندهید، یا مقدار آن را `null` بگذارید.

#### مثال‌های اشتباه (خطای کامپایل):

```Java
public class User {
    private var name = "Sue"; // خطا: var برای فیلد مجاز نیست

    public void setName(var name) { // خطا: var برای پارامتر مجاز نیست
        this.name = name;
    }
}
```

همچنین کد زیر کامپایل نمی‌شود، چون در زمان تعریف `greetings` هیچ مقداری به آن داده نشده تا نوعش مشخص شود:

```Java
public String greetings(int message) {
    var greetings; // خطا: مقداردهی اولیه نشده است
    if (message == 0) {
        greetings = "morning";
    } else {
        greetings = "afternoon";
    }
    return "Good " + greetings;
}
```

---

**نکته پایانی:** استفاده از `var` جاوا را به یک زبان با تایپ پویا (مثل پایتون) تبدیل نمی‌کند؛ جاوا همچنان **Statically-typed** است، فقط کامپایلر در نوشتن کد به شما کمک می‌کند تا کمتر تایپ کنید!
