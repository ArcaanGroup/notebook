## تعریف یک سازنده

یک کلاس شامل **سازنده‌هایی (Constructors)** است که برای ایجاد اشیاء از روی نقشه (blueprint) کلاس فراخوانی می‌شوند. اعلان سازنده شبیه به اعلان متد است؛ با این تفاوت که سازنده **هم‌نام با کلاس** است و **هیچ نوع بازگشتی** (حتی `void`) ندارد. برای مثال، کلاس `Bicycle` دارای یک سازنده است:

```Java
public Bicycle(int startCadence, int startSpeed, int startGear) {
    gear = startGear;
    cadence = startCadence;
    speed = startSpeed;
}
```

برای ایجاد یک شیء جدید از `Bicycle` به نام `myBike`، سازنده توسط عملگر `new` فراخوانی می‌شود:

```Java
Bicycle myBike = new Bicycle(30, 0, 8);
```

کد `new Bicycle(30, 0, 8)` فضایی را در حافظه برای شیء اختصاص داده و فیلدهای آن را مقداردهی اولیه می‌کند.

با اینکه `Bicycle` فقط یک سازنده دارد، می‌تواند سازنده‌های دیگری نیز داشته باشد، از جمله یک **سازنده بدون آرگومان** (no-argument constructor):

```Java
public Bicycle() {
    gear = 1;
    cadence = 10;
    speed = 0;
}
```

کد `Bicycle yourBike = new Bicycle();` سازنده بدون آرگومان را برای ایجاد شیء جدیدی به نام `yourBike` فراخوانی می‌کند.

---

#### سربارگذاری سازنده (Constructor Overloading)

هر دو سازنده فوق می‌توانند در کلاس `Bicycle` اعلان شوند زیرا لیست آرگومان‌های متفاوتی دارند. همانند متدها، پلتفرم جاوا سازنده‌ها را بر اساس **تعداد** و **نوع** آرگومان‌ها از هم تمایز می‌دهد. شما نمی‌توانید دو سازنده با تعداد و نوع آرگومان‌های کاملاً یکسان برای یک کلاس بنویسید، زیرا کامپایلر قادر به تشخیص آن‌ها از یکدیگر نخواهد بود و این کار باعث خطای زمان کامپایل می‌شود.

---

#### سازنده پیش‌فرض (Default Constructor)

شما مجبور نیستید برای کلاس خود سازنده‌ای بنویسید، اما باید در این کار دقت کنید. اگر کلاسی هیچ سازنده‌ای نداشته باشد، کامپایلر به طور خودکار یک **سازنده پیش‌فرض بدون آرگومان** برای آن فراهم می‌کند.

- این سازنده پیش‌فرض، سازنده بدون آرگومانِ **سوپرکلاس** (کلاس والد) را فراخوانی می‌کند.
    
- در این وضعیت، اگر سوپرکلاس سازنده بدون آرگومان نداشته باشد، کامپایلر خطا می‌دهد.
    
- اگر کلاس شما سوپرکلاس صریحی نداشته باشد، به طور ضمنی از کلاس `Object` ارث‌بری می‌کند که دارای سازنده بدون آرگومان است.

---

#### نکات تکمیلی

- شما می‌توانید از سازنده سوپرکلاس در بدنه سازنده خود استفاده کنید (مانند کلاس `MountainBike` که از `super` استفاده کرد).
    
- می‌توانید از **اصلاح‌گرهای دسترسی** (مانند `public` یا `private`) در اعلان سازنده استفاده کنید تا کنترل کنید چه کلاس‌های دیگری مجاز به ساختن شیء از این کلاس هستند.
