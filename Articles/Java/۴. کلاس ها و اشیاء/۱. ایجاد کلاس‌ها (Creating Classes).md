## اعلان کلاس‌ها (Declaring Classes)

مفاهیم شیءگرا پیش‌تر با مثال کلاس `Bicycle` معرفی شدند که دوچرخه‌های مسابقه‌ای، کوهستان و دو نفره زیرکلاس‌های (subclasses) آن بودند. در ادامه، نمونه کدی برای پیاده‌سازی احتمالی کلاس `Bicycle` آورده شده است تا دیدی کلی از اعلان یک کلاس داشته باشید. بخش‌های بعدی مرحله به مرحله این اعلان‌ها را توضیح خواهند داد؛ بنابراین فعلاً نگران جزئیات نباشید.

```Java
public class Bicycle {
        
    // کلاس Bicycle دارای سه فیلد است
    public int cadence;
    public int gear;
    public int speed;
        
    // کلاس Bicycle دارای یک سازنده (Constructor) است
    public Bicycle(int startCadence, int startSpeed, int startGear) {
        gear = startGear;
        cadence = startCadence;
        speed = startSpeed;
    }
        
    // کلاس Bicycle دارای چهار متد است
    public void setCadence(int newValue) {
        cadence = newValue;
    }
        
    public void setGear(int newValue) {
        gear = newValue;
    }
        
    public void applyBrake(int decrement) {
        speed -= decrement;
    }
        
    public void speedUp(int increment) {
        speed += increment;
    }
}
```

اعلان کلاس `MountainBike` که زیرکلاسی از `Bicycle` است، ممکن است به این صورت باشد:

```Java
public class MountainBike extends Bicycle {
        
    // زیرکلاس MountainBike دارای یک فیلد است
    public int seatHeight;

    // زیرکلاس MountainBike دارای یک سازنده است
    public MountainBike(int startHeight, int startCadence,
                        int startSpeed, int startGear) {
        super(startCadence, startSpeed, startGear);
        seatHeight = startHeight;
    }   
        
    // زیرکلاس MountainBike دارای یک متد است
    public void setHeight(int newValue) {
        seatHeight = newValue;
    }   
}
```

کلاس `MountainBike` تمام فیلدها و متدهای `Bicycle` را به ارث می‌برد و فیلد `seatHeight` و متدی برای تنظیم آن را اضافه می‌کند (دوچرخه‌های کوهستان صندلی‌هایی دارند که بر اساس نیاز زمین، بالا و پایین می‌روند).

شما پیش از این کلاس‌ها را به این صورت تعریف شده دیده‌اید:

```Java
class MyClass {
    // اعلان فیلدها، سازنده‌ها و متدها
}
```

این یک اعلان کلاس است. **بدنه کلاس** (ناحیه بین ابروها `{}`) شامل تمام کدی است که چرخه حیات اشیاء ساخته شده از کلاس را فراهم می‌کند: **سازنده‌ها** برای مقداردهی اولیه اشیاء جدید، **اعلان فیلدها** که وضعیت (state) کلاس و اشیاء آن را فراهم می‌کنند، و **متدها** برای پیاده‌سازی رفتار (behavior) کلاس و اشیاء آن.

اعلان کلاس قبلی یک اعلان حداقلی بود و تنها شامل اجزای ضروری بود. شما می‌توانید اطلاعات بیشتری درباره کلاس ارائه دهید، مانند نام سوپرکلاس (Superclass)، اینکه آیا رابطی (Interface) را پیاده‌سازی می‌کند یا خیر و غیره. به عنوان مثال:

```Java
class MyClass extends MySuperClass implements YourInterface {
    // اعلان فیلدها، سازنده‌ها و متدها
}
```

این به این معنی است که `MyClass` زیرکلاسی از `MySuperClass` است و رابط `YourInterface` را پیاده‌سازی می‌کند. همچنین می‌توانید اصلاح‌گرهایی (Modifiers) مانند `public` یا `private` را در ابتدای خط اضافه کنید. اصلاح‌گرهای `public` و `private` که تعیین می‌کنند چه کلاس‌های دیگری به `MyClass` دسترسی داشته باشند، بعداً بررسی می‌شوند.

به طور کلی، اعلان‌های کلاس می‌توانند شامل این اجزا به ترتیب زیر باشند:

1. **اصلاح‌گرها (Modifiers):** مانند `public` ، `private` و موارد دیگر (اصلاح‌گر `private` تنها برای کلاس‌های تودرتو کاربرد دارد).
    
2. **نام کلاس:** که طبق قرارداد، حرف اول آن بزرگ (Capitalized) نوشته می‌شود.
    
3. **نام والد (Superclass):** در صورت وجود، که قبل از آن کلمه کلیدی `extends` می‌آید. هر کلاس تنها می‌تواند یک والد داشته باشد.
    
4. **لیست رابط‌ها (Interfaces):** در صورت وجود، که با ویرگول از هم جدا شده و قبل از آن‌ها کلمه کلیدی `implements` می‌آید. یک کلاس می‌تواند بیش از یک رابط را پیاده‌سازی کند.
    
5. **بدنه کلاس:** که محصور در ابروها `{}` است.


## اعلان متغیرهای عضو (Declaring Member Variables)

در زبان جاوا چندین نوع متغیر وجود دارد:

- **متغیرهای عضو در یک کلاس:** این متغیرها **فیلد (field)** نامیده می‌شوند.
    
- **متغیرهای درون یک متد یا بلوک کد:** این‌ها **متغیرهای محلی (local variables)** نامیده می‌شوند.
    
- **متغیرهای موجود در اعلان متدها:** این‌ها **پارامتر (parameters)** نامیده می‌شوند.

کلاس `Bicycle` از خطوط کد زیر برای تعریف فیلدهای خود استفاده می‌کند:

```Java
public int cadence;
public int gear;
public int speed;
```

اعلان یک فیلد از سه جزء تشکیل شده است که به ترتیب عبارتند از:

1. صفر یا چند **اصلاح‌گر (modifier)**، مانند `public` یا `private`.
    
2. **نوع (type)** فیلد.
    
3. **نام (name)** فیلد.

فیلدهای کلاس `Bicycle` با نام‌های `cadence` ، `gear` و `speed` شناخته می‌شوند و همگی از نوع داده صحیح (`int`) هستند. کلمه کلیدی `public` این فیلدها را به عنوان اعضای عمومی شناسایی می‌کند که توسط هر شیئی که به کلاس دسترسی داشته باشد، قابل دسترسی هستند.

---

### کنترل دسترسی به یک عضو (Access Control)

اولین اصلاح‌گر (سمت چپ‌ترین) به شما اجازه می‌دهد کنترل کنید که چه کلاس‌های دیگری به یک فیلد دسترسی داشته باشند. در حال حاضر، فقط `public` و `private` را در نظر بگیرید:

- **اصلاح‌گر public:** فیلد از تمامی کلاس‌ها قابل دسترسی است.
    
- **اصلاح‌گر private:** فیلد تنها در داخل کلاس خودش قابل دسترسی است.

در راستای اصل **کپسوله‌سازی (Encapsulation)**، معمول است که فیلدها به صورت `private` تعریف شوند. این بدان معناست که آن‌ها فقط به طور مستقیم از درون کلاس `Bicycle` قابل دسترسی هستند. با این حال، ما همچنان به این مقادیر نیاز داریم. این کار را می‌توان به صورت غیرمستقیم و با افزودن متدهای `public` که مقادیر فیلد را برای ما دریافت یا تنظیم می‌کنند، انجام داد:

```Java
public class Bicycle {
        
    private int cadence;
    private int gear;
    private int speed;
        
    public Bicycle(int startCadence, int startSpeed, int startGear) {
        gear = startGear;
        cadence = startCadence;
        speed = startSpeed;
    }
        
    public int getCadence() {
        return cadence;
    }
        
    public void setCadence(int newValue) {
        cadence = newValue;
    }
    
    // سایر متدهای Getter و Setter...
}
```

---

### تعیین نوع متغیر (Setting the Type)

تمام متغیرها باید دارای یک نوع باشند. شما می‌توانید از **انواع اولیه (primitive types)** مانند `int` ، `float` ، `boolean` و غیره استفاده کنید، یا از **انواع مرجع (reference types)** مانند رشته‌ها (`Strings`)، آرایه‌ها یا اشیاء استفاده نمایید.

---

### نام‌گذاری متغیر (Naming a Variable)

تمام متغیرها (فیلدها، متغیرهای محلی یا پارامترها) از همان قوانین و قراردادهای نام‌گذاری پیروی می‌کنند که در بخش مبانی زبان بررسی شد. در این بخش، توجه داشته باشید که همان قوانین برای نام متدها و کلاس‌ها نیز به کار می‌رود، با این تفاوت که:

- حرف اول نام یک **کلاس** باید بزرگ باشد.
    
- اولین (یا تنها) کلمه در نام یک **متد** باید یک فعل باشد.
