جاوا فقط یک زبان برنامه‌نویسی نیست؛ بلکه یک **پلتفرم** است. برای اینکه بتوانید کدهای جاوا را بنویسید و اجرا کنید، به بسته‌ای به نام **JDK** (مخفف Java Development Kit) نیاز دارید.

### مرحله اول: نصب JDK

برخلاف گذشته که نصب جاوا کمی پیچیده بود، امروزه اوراکل و جامعه متن‌باز جاوا، نصب آن را بسیار ساده کرده‌اند.

- **JDK چیست؟** مجموعه‌ای از ابزارها شامل کامپایلر (javac) و محیط اجرا (JRE) که برای توسعه برنامه‌های جاوا ضروری است.
    
- **چه نسخه‌ای نصب کنیم؟** پیشنهاد می‌شود همیشه از نسخه‌های **LTS** (پشتیبانی بلندمدت) استفاده کنید. در حال حاضر نسخه **۱۷** و **۲۱** محبوب‌ترین نسخه‌های پایدار هستند.

**لینک دریافت:**

شما می‌توانید نسخه مناسب سیستم‌عامل خود (ویندوز، مک یا لینوکس) را از [اینجا در سایت اوراکل](https://www.oracle.com/java/technologies/downloads/) دریافت کنید.

### مرحله دوم: نوشتن اولین برنامه (Hello World)

در جاوا، هر خط کد باید درون یک **Class** (کلاس) قرار بگیرد. بیایید یک فایل متنی ساده بسازیم و نام آن را `Main.java` بگذاریم.

**کد برنامه:**

```java
/**
 * اولین برنامه جاوای من
 */
public class Main {
    public static void main(String[] args) {
        // چاپ متن در خروجی (کنسول)
        System.out.println("سلام دنیا! به دنیای جاوا خوش آمدید.");
    }
}
```

#### کالبدشکافی کد بالا به زبان ساده:

- **`public class Main`**: در جاوا، نام کلاس باید با نام فایل یکی باشد. کلمه `public` یعنی این کلاس برای همه قابل دسترسی است.
    
- **`public static void main`**: این "نقطه ورود" (Entry Point) برنامه است. هر برنامه‌ای که بخواهد اجرا شود، باید این متد را داشته باشد.
    
- **`System.out.println`**: دستوری است که متنی را در کنسول یا محیط خروجی چاپ می‌کند.

### مرحله سوم: کامپایل و اجرا (بدون نیاز به IDE)

اگر می‌خواهید بدانید در پشت صحنه چه اتفاقی می‌افتد، می‌توانید از خط فرمان (Command Prompt یا Terminal) استفاده کنید:

1. **کامپایل کردن:** این کار کد شما را به "بایت‌کد" (Bytecode) تبدیل می‌کند که برای ماشین قابل فهم است.
    
    Bash
    
    ```
    javac Main.java
    ```
    
    _(با این کار فایلی به نام `Main.class` ساخته می‌شود)_
    
2. **اجرا کردن:**
    
    Bash
    
    ```
    java Main
    ```
    
    **خروجی:** `سلام دنیا! به دنیای جاوا خوش آمدید.`

### نکته مدرن (در جاوا ۱۱ به بعد):

در نسخه‌های جدید، اگر برنامه شما فقط یک فایل ساده است، می‌توانید مستقیماً با دستور زیر آن را اجرا کنید (بدون نیاز به مرحله کامپایل جداگانه):

Bash

```
java Main.java
```
