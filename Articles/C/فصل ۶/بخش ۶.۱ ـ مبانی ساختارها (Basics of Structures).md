وارد **فصل ششم** می‌شویم؛ فصلی که به ما اجازه می‌دهد داده‌های مرتبط با هم را (که لزوماً هم‌نوع نیستند) زیر یک چتر واحد جمع کنیم. این مفهوم، پایه و اساس شیءگرایی در زبان‌های بعدی شد.

یک **ساختار (Structure)** مجموعه‌ای از یک یا چند متغیر است که احتمالاً از انواع مختلف هستند و برای راحتی کار، تحت یک نام گروه‌بندی شده‌اند.

### ۱. تعریف ساختار

کلاسیک‌ترین مثال کتاب K&R، تعریف یک نقطه در صفحه مختصات است:

```c
struct point {
    int x;
    int y;
};
```

- **`struct`**: کلمه کلیدی برای شروع تعریف.
    
- **`point`**: برچسب (Tag) ساختار که برای مراجعات بعدی استفاده می‌شود.
    
- **`x` و `y`**: اعضای (Members) ساختار نامیده می‌شوند.

### ۲. استفاده و مقداردهی

بعد از تعریف قالب، می‌توانید متغیرهایی از آن نوع بسازید:

```c
struct point pt = { 320, 200 };
```

برای دسترسی به اعضا، از عملگر **نقطه (`.`)** استفاده می‌کنیم:

`printf("%d,%d", pt.x, pt.y);`
