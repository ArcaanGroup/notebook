دستور `typedef` ابزاری است که به شما اجازه می‌دهد برای انواع داده‌ها (Data Types) یک **نام مستعار (Alias)** ایجاد کنید. دقت کنید که این دستور نوع جدیدی ایجاد نمی‌کند، بلکه فقط یک نام جدید برای انواع موجود تعریف می‌کند.

### ۱. ساختار دستور:

```c
typedef int Length;
```

بعد از این خط، شما می‌توانید به جای `int` از کلمه `Length` استفاده کنید:

`Length len, maxlen;`

### ۲. کاربرد در ساختارها (بسیار رایج)

به جای اینکه هر بار بنویسید `struct tnode *` که طولانی و خسته‌کننده است، می‌توانید یک نام کوتاه‌تر بسازید:

```c
typedef struct tnode {
    char *word;
    int count;
    struct tnode *left;
    struct tnode *right;
} Treenode;

/* حالا می‌توانید به این سادگی متغیر تعریف کنید */
Treenode *root;
```

### ۳. چرا از `typedef` استفاده می‌کنیم؟

K&R سه دلیل اصلی ذکر می‌کنند:

1. **خوانایی کد:** نام‌هایی مثل `Length` یا `FilePtr` بیشتر از `int` یا `struct _iobuf *` درباره محتوای متغیر توضیح می‌دهند.
    
2. **پرتابل بودن (Portability):** اگر برنامه‌ای بنویسید که به اندازه دقیق بیت‌های یک متغیر وابسته باشد، می‌توانید آن را `typedef` کنید. اگر برنامه را به کامپیوتر دیگری ببرید، فقط کافی است همان یک خط `typedef` را اصلاح کنید.
    
3. **ساده‌سازی تعاریف پیچیده:** تعریف اشاره‌گر به توابع با `typedef` بسیار ساده‌تر و قابل‌فهم‌تر می‌شود.
