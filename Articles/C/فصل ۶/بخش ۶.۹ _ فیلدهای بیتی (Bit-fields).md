وقتی فضای حافظه بسیار محدود است (مثلاً در برنامه‌نویسی سخت‌افزار یا سیستم‌عامل)، ممکن است بخواهید چندین متغیر را در بایت‌های یک کلمه (Word) ذخیره کنید. C اجازه می‌دهد اعضای یک ساختار را به صورت **تعداد بیت مشخص** تعریف کنید.

```c
struct {
    unsigned int is_keyword : 1;
    unsigned int is_static  : 1;
    unsigned int is_extern  : 1;
} flags;
```

در اینجا هر کدام از این متغیرها فقط **۱ بیت** از حافظه را اشغال می‌کنند.
