شما می‌توانید ساختارها را به توابع پاس دهید یا از آن‌ها به عنوان خروجی استفاده کنید. کتاب سه روش را پیشنهاد می‌دهد:

1. **پاس دادن اعضا به صورت جداگانه:** (مثل `makepoint(pt.x, pt.y)`).
    
2. **پاس دادن کل ساختار:** در این حالت کل داده کپی می‌شود.
    
3. **پاس دادن اشاره‌گر به ساختار:** این روش سریع‌تر است چون فقط یک آدرس کپی می‌شود.

### تابع `makepoint`

این تابع دو عدد می‌گیرد و یک ساختار `point` برمی‌گرداند:

```c
struct point makepoint(int x, int y)
{
    struct point temp;
    temp.x = x;
    temp.y = y;
    return temp;
}
```
