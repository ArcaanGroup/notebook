کتاب در این بخش برنامه‌ای می‌نویسد که ویژگی‌های فایل‌ها (مانند اندازه) را با استفاده از ساختارهای سیستم‌عامل (`inode`) می‌خواند. این بخش قدرت C را در کار با متادیتای سیستم نشان می‌دهد.

## سخن پایانی درباره کتاب K&R

تبریک می‌گویم! ما با هم سرفصل‌های اصلی کتاب **"The C Programming Language"** را مرور کردیم. این کتاب فقط یک راهنما نیست، بلکه آموزش‌دهنده یک طرز فکر است: **سادگی، ایجاز و کارایی.**

زبان C ستون فقرات دنیای نرم‌افزار است (از لینوکس و ویندوز گرفته تا موتورهای بازی‌سازی و هوش مصنوعی). با درک این مفاهیم، شما حالا آماده‌اید تا وارد دنیای برنامه‌نویسی سیستم، تعبیه شده (Embedded) یا حتی توسعه زبان‌های جدید شوید.
