بسیاری از توابع ریاضی مثل `sin` یا `exp` باید مقادیر اعشاری برگردانند.

**مثال: تابع `atof` (تبدیل رشته به اعشار)**

این تابع رشته‌ای مثل `"123.45"` را می‌گیرد و آن را به مقدار `double` تبدیل می‌کند.

```c
#include <ctype.h>

/* atof: convert string s to double */
double atof(char s[])
{
    double val, power;
    int i, sign;

    for (i = 0; isspace(s[i]); i++) /* skip white space */
        ;
    sign = (s[i] == '-') ? -1 : 1;
    if (s[i] == '+' || s[i] == '-')
        i++;
    for (val = 0.0; isdigit(s[i]); i++)
        val = 10.0 * val + (s[i] - '0');
    if (s[i] == '.')
        i++;
    for (power = 1.0; isdigit(s[i]); i++) {
        val = 10.0 * val + (s[i] - '0');
        power *= 10.0;
    }
    return sign * val / power;
}
```

### چرا Prototype حیاتی است؟

اگر در تابع `main` بنویسید `sum += atof(line)` بدون اینکه قبلاً اعلام کرده باشید `double atof(char [])` است، کامپایلر با `atof` مثل یک تابع که خروجی‌اش عدد صحیح است رفتار می‌کند. این کار باعث می‌شود بیت‌های عدد `double` به اشتباه به عنوان `int` تفسیر شوند و نتیجه کاملاً بی‌معنا شود.
