زبان C دستور `goto` را برای پرش مستقیم به یک برچسب (Label) در همان تابع فراهم کرده است.

### ۱. ساختار:

```C
    goto label;
    ...
label:
    statement;
```

### ۲. دیدگاه K&R درباره `goto`:

نویسندگان کتاب (مانند اکثر برنامه‌نویسان حرفه‌ای) معتقدند که `goto` پتانسیل زیادی برای تبدیل کردن کد به "اسپاگتی" (کد ناخوانا و غیرقابل ردیابی) دارد. تقریباً تمام کارهایی که با `goto` انجام می‌شود را می‌توان با ساختارهای `if`, `while` و `break` به شکلی تمیزتر نوشت.

**تنها مورد استثنای منطقی:**

خروج از چندین حلقه تو در تو به صورت همزمان. از آنجا که `break` فقط از یک حلقه خارج می‌شود، برای خروج از ۳ حلقه متداخل، یک `goto` می‌تواند کد را ساده‌تر کند:

```c
    for (...)
        for (...)
            if (disaster)
                goto error;
    ...
error:
    /* مدیریت خطا یا پاکسازی حافظه */
```

## جمع‌بندی فصل ۳:

فصل سوم به ما یاد داد که چگونه با:

- `if-else` و `switch` تصمیم بگیریم.
    
- با `while`, `for` و `do-while` تکرار کنیم.
    
- و با `break` و `continue` جریان این تکرارها را کنترل کنیم.
