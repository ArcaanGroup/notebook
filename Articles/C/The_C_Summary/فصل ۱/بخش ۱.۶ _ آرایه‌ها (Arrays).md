در بخش‌های قبلی، ما فقط تعداد کل کاراکترها یا کلمات را می‌شمردیم. اما اگر بخواهیم تعداد تکرار هر رقم (۰ تا ۹) را به صورت جداگانه بشماریم، به جای تعریف ۱۰ متغیر مجزا، از یک **آرایه** استفاده می‌کنیم.

### ۱. کد نمونه: شمارش ارقام، فواصل سفید و سایر کاراکترها

```c
#include <stdio.h>

/* count digits, white space, others */
main()
{
    int c, i, nwhite, nother;
    int ndigit[10];

    nwhite = nother = 0;
    for (i = 0; i < 10; ++i)
        ndigit[i] = 0;

    while ((c = getchar()) != EOF)
        if (c >= '0' && c <= '9')
            ++ndigit[c-'0'];
        else if (c == ' ' || c == '\n' || c == '\t')
            ++nwhite;
        else
            ++nother;

    printf("digits =");
    for (i = 0; i < 10; ++i)
        printf(" %d", ndigit[i]);
    printf(", white space = %d, other = %d\n", nwhite, nother);
}
```

### ۲. نکات علمی و فنی آرایه‌ها در C

- **تعریف آرایه:** عبارت `int ndigit[10];` ده فضای حافظه برای اعداد صحیح رزرو می‌کند.
    
- **ایندکس‌گذاری (Indexing):** در زبان C، شمارش ایندکس‌ها همیشه از **۰** شروع می‌شود. بنابراین خانه‌های این آرایه از `ndigit[0]` تا `ndigit[9]` هستند.
    
- **دسترسی به عناصر:** برای دسترسی به یک خانه، از کروشه `[]` استفاده می‌کنیم. برای مثال، `ndigit[i]` مقدار خانه `i`-ام را برمی‌گرداند.
    
- **تناظر کاراکتر و ایندکس:** عبارت کلیدی `ndigit[c-'0']` بسیار هوشمندانه است. اگر کاراکتر `c` برابر `'5'` باشد، طبق جدول اسکی، حاصل `'5' - '0'` دقیقاً عدد **۵** می‌شود که همان ایندکس مورد نظر ما در آرایه است.   

### ۳. ساختار `else if`

این بخش همچنین ساختار تصمیم‌گیری چندگانه را معرفی می‌کند. این الگو برای بررسی چندین شرط متوالی استفاده می‌شود:

```c
if (condition1)
    statement1
else if (condition2)
    statement2
else
    statementN
```

شرط‌ها از بالا به پایین چک می‌شوند و به محض اینکه یکی درست باشد، بخش مربوطه اجرا شده و بقیه نادیده گرفته می‌شوند.
