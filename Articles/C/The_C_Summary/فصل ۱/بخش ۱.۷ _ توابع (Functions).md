در C، توابع به ما اجازه می‌دهند یک قطعه کد را بسته‌بندی کرده و بارها از آن استفاده کنیم. این کار باعث جلوگیری از تکرار کد و بالا رفتن نظم برنامه می‌شود.

### ۱. مثال: تابع توان ($power$)

کتاب تابعی به نام `power(m, n)` می‌نویسد که عدد $m$ را به توان $n$ می‌رساند.

```c
#include <stdio.h>

int power(int m, int n); /* function prototype */

/* test power function */
main()
{
    int i;
    for (i = 0; i < 10; ++i)
        printf("%d %d %d\n", i, power(2,i), power(-3,i));
    return 0;
}

/* power: raise base to n-th power; n >= 0 */
int power(int base, int n)
{
    int i, p;
    p = 1;
    for (i = 1; i <= n; ++i)
        p = p * base;
    return p;
}
```

### ۲. اجزای یک تابع

1. **پروتوتایپ (Prototype):** خط `int power(int m, int n);` قبل از `main` به کامپایلر می‌گوید که چنین تابعی با این مشخصات وجود دارد. این کار باعث می‌شود اگر در `main` اشتباهی در ارسال پارامترها انجام دهیم، کامپایلر به ما هشدار دهد.
    
2. **پارامترها (Parameters):** متغیرهایی که در تعریف تابع می‌آیند (مثل `base` و `n`).
    
3. **آرگومان‌ها (Arguments):** مقادیری که هنگام فراخوانی به تابع پاس می‌دهیم (مثل `2` و `i`).
    
4. **مقدار بازگشتی (`return`):** نتیجه‌ای که تابع به فراخوان‌کننده پس می‌دهد.
