نویسندگان کتاب معتقدند تنها راه یادگیری زبان، نوشتن برنامه است. اولین برنامه کلاسیک تاریخ، یعنی "hello, world"، در این بخش متولد شد.

### ۱. برنامه Hello World

ساختار برنامه به شکل زیر است:

```c
#include <stdio.h>

main()
{
    printf("hello, world\n");
}
```

- **`#include <stdio.h>`**: این خط به کامپایلر می‌گوید که اطلاعات مربوط به کتابخانه استاندارد ورودی و خروجی را شامل شود. بدون این خط، کامپایلر نمی‌داند `printf` چیست.
    
- **`main()`**: هر برنامه C از اینجا شروع می‌شود. تمام برنامه‌ها باید یک تابع `main` داشته باشند.
    
- **`{ }`**: براکت‌ها محدوده بدنه تابع را مشخص می‌کنند.
    
- **`printf(...)`**: تابعی است که متن را در خروجی چاپ می‌کند.
    
- **`\n`**: نشان‌دهنده کاراکتر "سطر جدید" (newline) است.

### ۲. فرآیند اجرای برنامه

کتاب توضیح می‌دهد که برخلاف برخی زبان‌ها، شما نمی‌توانید کد C را مستقیماً اجرا کنید. مراحل به این صورت است:

1. نوشتن کد در یک فایل متنی با پسوند `.c` (مثلاً `hello.c`).
    
2. **کامپایل کردن:** استفاده از یک کامپایلر (مانند `cc` یا `gcc`) برای تبدیل کد به یک فایل قابل اجرا.
    
    - دستور معمول در سیستم‌های یونیکس: `cc hello.c`
        
    - این دستور فایلی به نام `a.out` تولید می‌کند.
        
3. **اجرا:** فراخوانی فایل تولید شده با دستور `./a.out`.

### ۳. کاراکترهای کنترلی (Escape Sequences)

در C، برخی کاراکترها با علامت `\` شروع می‌شوند تا مفاهیم خاصی را برسانند. در بخش ۱.۱ به موارد زیر اشاره شده است:

- `\n` : Newline (سطر جدید)
    
- `\t` : Tab (فاصله افقی)
    
- `\b` : Backspace (حذف کاراکتر قبلی)
    
- `\"` : چاپ کردن خودِ علامت کوتیشن
    
- `\\` : چاپ کردن خودِ علامت بک‌اسلش

> **نکته علمی از K&R:** تابع `printf` هرگز به صورت خودکار به انتهای متن سطر جدید اضافه نمی‌کند. به همین دلیل استفاده از `\n` برای نظم دادن به خروجی ضروری است. اگر چندین `printf` پشت سر هم بنویسید و از `\n` استفاده نکنید، همه خروجی‌ها در یک خط به هم می‌چسبند.
