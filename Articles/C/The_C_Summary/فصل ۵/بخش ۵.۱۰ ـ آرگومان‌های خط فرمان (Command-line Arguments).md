در محیط‌هایی که C اجرا می‌شود (مثل Unix یا Windows)، می‌توان هنگام اجرای برنامه، پارامترهایی را به آن پاس داد. این کار از طریق دو آرگومان در تابع `main` انجام می‌شود:

```c
main(int argc, char *argv[])
```

- **`argc` (Argument Count):** تعداد کلمات تایپ شده در خط فرمان (شامل نام خود برنامه).
    
- **`argv` (Argument Vector):** آرایه‌ای از اشاره‌گرها به رشته‌هایی که همان کلمات ورودی هستند.
    
    - `argv[0]` همیشه نام خود برنامه است.
        
    - `argv[argc]` همیشه `NULL` است.

### مثال: برنامه `echo` (نسخه اشاره‌گری)

برنامه‌ای که آرگومان‌های خود را چاپ می‌کند:

```c
#include <stdio.h>

/* echo command-line arguments; 2nd version */
main(int argc, char *argv[])
{
    while (--argc > 0)
        printf("%s%s", *++argv, (argc > 1) ? " " : "");
    printf("\n");
    return 0;
}
```

- **توضیح علمی:** در اینجا `++argv` اشاره‌گر را به سمت آرگومان بعدی حرکت می‌دهد و `*` مقدار آن (رشته) را برای چاپ بیرون می‌کشد.
