در C، یک **رشته ثابت** (String Constant) مانند `"hello, world"` در واقع یک آرایه از کاراکترهاست. کامپایلر این رشته را در جایی از حافظه ذخیره می‌کند و یک اشاره‌گر به اولین کاراکتر آن برمی‌گرداند.

### ۱. تفاوت مهم: آرایه در مقابل اشاره‌گر

درک این تفاوت برای هر برنامه‌نویس C حیاتی است:

- **`char amessage[] = "now is the time";`**
    
    این یک **آرایه** است. شما می‌توانید محتوای خانه‌های آن را عوض کنید، اما نام `amessage` همیشه به یک نقطه ثابت از حافظه اشاره می‌کند.
    
- **`char *pmessage = "now is the time";`**
    
    این یک **اشاره‌گر** است. `pmessage` به یک رشته ثابت (غالباً در بخش Read-only حافظه) اشاره می‌کند. شما می‌توانید `pmessage` را تغییر دهید تا به جای دیگری اشاره کند، اما تغییر دادنِ خودِ کاراکترهای آن رشته ممکن است باعث کرش کردن برنامه شود.

### ۲. پیاده‌سازی تابع `strcpy`

برای کپی کردن رشته `t` در `s` (نسخه آرایه‌ای):

```C
void strcpy(char *s, char *t) {
    int i = 0;
    while ((s[i] = t[i]) != '\0')
        i++;
}
```

نسخه **ایجازگونه (Idiomatic)** با اشاره‌گر که در دنیای C حرفه‌ای بسیار رایج است:

```c
void strcpy(char *s, char *t) {
    while ((*s++ = *t++))
        ;
}
```

- **توضیح علمی:** در اینجا کپی کردن کاراکتر، افزایش اشاره‌گرها و چک کردن شرط پایان (رسیدن به `\0` که مقدارش صفر است) همگی در یک خط انجام می‌شوند.
