یک اشاره‌گر، متغیری است که **آدرس** یک متغیر دیگر را در خود نگه می‌دارد. در C، حافظه را می‌توان به صورت ردیفی از سلول‌های شماره‌گذاری شده (بایت‌ها) تصور کرد که هر کدام یک آدرس دارند.

### ۱. عملگرهای کلیدی

برای کار با اشاره‌گرها، دو عملگر مخصوص داریم:

- **`&` (Unary operator):** آدرس یک شیء را برمی‌گرداند.
    
    - مثال: `p = &c;` (آدرس متغیر `c` را در `p` بریز).
        
- **`*` (Indirection / Dereferencing):** به محتوای آدرسی که اشاره‌گر به آن اشاره می‌کند، دسترسی پیدا می‌کند.
    
    - مثال: `x = *p;` (مقداری که در آدرس `p` قرار دارد را در `x` بریز).

### ۲. اعلان اشاره‌گر

هنگام تعریف، باید نوع متغیری که اشاره‌گر به آن اشاره خواهد کرد را مشخص کنیم:

```C
int x = 1, y = 2, z[10];
int *ip;    /* ip یک اشاره‌گر به عدد صحیح است */

ip = &x;    /* حالا ip به x اشاره می‌کند */
y = *ip;    /* حالا y برابر با 1 است */
*ip = 0;    /* حالا x برابر با 0 است */
ip = &z[0]; /* حالا ip به اولین خانه آرایه z اشاره می‌کند */
```
