تا اینجا فقط با `stdin` و `stdout` کار کردیم. برای کار با فایل‌های واقعی روی دیسک، نیاز به اشاره‌گری از نوع **`FILE`** داریم.

### ۱. باز کردن فایل (`fopen`)

```c
FILE *fp;
fp = fopen("filename", "r");
```

- `"r"`: برای خواندن (Read).
    
- `"w"`: برای نوشتن (Write) - محتوای قبلی فایل پاک می‌شود.
    
- `"a"`: برای اضافه کردن به انتهای فایل (Append).

### ۲. خواندن و نوشتن در فایل

به جای `getchar` و `putchar` از توابع زیر استفاده می‌کنیم که یک آرگومان اضافه (اشاره‌گر فایل) می‌گیرند:

- `getc(fp)`
    
- `putc(c, fp)`
    
- `fprintf(fp, "format", ...)`
    
- `fscanf(fp, "format", ...)`

### ۳. بستن فایل (`fclose`)

همیشه بعد از اتمام کار، فایل را ببندید تا منابع سیستم آزاد شود: `fclose(fp);`
