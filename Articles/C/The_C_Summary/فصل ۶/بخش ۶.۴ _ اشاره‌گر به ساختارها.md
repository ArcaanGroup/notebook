اگر بخواهیم از اشاره‌گر برای دسترسی به اعضای یک ساختار استفاده کنیم، C یک عملگر ویژه و بسیار پرکاربرد به نام **`->` (عملگر فلش)** ارائه داده است.

اگر `pp` اشاره‌گری به یک ساختار باشد:

- عبارت `(*pp).x` معادل است با `pp->x`.

این کوتاه‌نویسی در برنامه‌نویسی سیستم بسیار رایج است:

```c
struct point pt = {10, 20};
struct point *pp = &pt;

printf("origin is (%d,%d)\n", pp->x, pp->y);
```
