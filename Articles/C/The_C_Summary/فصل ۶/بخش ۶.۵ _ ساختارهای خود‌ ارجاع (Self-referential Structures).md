این بخش زیربنای ساختارهای داده پیشرفته مثل **درخت‌ها (Trees)** و **لیست‌های پیوندی (Linked Lists)** است. یک ساختار می‌تواند شامل اشاره‌گری به نمونه‌ای از خودش باشد.

**مثال: گره یک درخت جستجوی دودویی (Binary Search Tree):**

```c
struct tnode {
    char *word;           /* متن گره */
    int count;            /* تعداد تکرار */
    struct tnode *left;   /* فرزند چپ */
    struct tnode *right;  /* فرزند راست */
};
```
