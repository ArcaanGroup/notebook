این عملگر که به **عملگر سه‌تایی (Ternary Operator)** معروف است، تنها عملگر C است که سه اپراند می‌گیرد. این یک جایگزین جمع‌وجور برای دستور `if-else` ساده است.

### ساختار:

`expr1 ? expr2 : expr3`

- اگر `expr1` درست باشد، مقدار کل عبارت برابر با `expr2` است.
    
- اگر `expr1` غلط باشد، مقدار کل عبارت برابر با `expr3` است.

**مثال:** پیدا کردن ماکزیمم دو عدد:

```c
z = (a > b) ? a : b;  /* z = max(a, b) */
```
