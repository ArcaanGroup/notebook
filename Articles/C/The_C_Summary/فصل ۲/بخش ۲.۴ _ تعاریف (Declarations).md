در زبان C، هر متغیر پیش از آنکه مورد استفاده قرار گیرد، باید **تعریف (Declare)** شود. یک تعریف، نوع متغیر را مشخص کرده و لیستی از یک یا چند متغیر از آن نوع را شامل می‌شود.

### ۱. ساختار ساده تعاریف

نمونه‌های استاندارد تعریف متغیر به صورت زیر است:

```c
int lower, upper, step;
char c, line[1000];
```

می‌توان متغیرها را به صورت جداگانه نیز تعریف کرد که خوانایی کد را برای افزودن توضیحات (Comments) بالا می‌برد:

```c
int lower;    /* lower limit of temperature table */
int upper;    /* upper limit */
int step;     /* step size */
```

### ۲. مقداردهی اولیه (Initialization)

متغیرها را می‌توان در همان لحظه‌ی تعریف، مقداردهی کرد. اگر نام متغیر با یک علامت مساوی و یک **عبارت (Expression)** دنبال شود، آن عبارت به عنوان مقدار اولیه در نظر گرفته می‌شود:

```c
char esc = '\\';
int i = 0;
int limit = MAXLINE + 1;
float eps = 1.0e-5;
```

- **متغیرهای خارجی و استاتیک (External & Static):** به صورت پیش‌فرض با مقدار **صفر** مقداردهی می‌شوند.
    
- **متغیرهای اتوماتیک (Automatic):** (متغیرهایی که داخل یک تابع تعریف می‌شوند) اگر مقداردهی اولیه نشوند، دارای مقداری نامشخص (Garbage Value) هستند.

### ۳. اصلاح‌گر `const`

کلمه کلیدی `const` (که در استانداردهای جدیدتر به C اضافه شد) به ابتدای تعریف متغیر اضافه می‌شود تا اعلام کند که مقدار این متغیر **تغییرناپذیر** است.

C

```c
const double pi = 3.14159265358979323846;
const char msg[] = "warning: ";
```

- **کاربرد در آرایه‌ها:** اگر یک آرایه را `const` تعریف کنید، یعنی عناصر آن آرایه نباید تغییر کنند.
    
- **کاربرد در توابع:** این اصلاح‌گر بسیار مفید است تا به تابع بگویید مجاز به تغییر آرایه‌ای که به عنوان ورودی دریافت کرده، نیست.
