زمانی که یک اپراند از یک نوع داده با اپراندی از نوع دیگر در یک عبارت ترکیب می‌شود، سی آن‌ها را به یک نوع مشترک تبدیل می‌کند. K&R این موضوع را به دو دسته **خودکار (Automatic)** و **اجباری (Casting)** تقسیم می‌کند.

### ۱. ترفیع خودکار (Automatic Conversion)

به طور کلی، C انواع "کوچک‌تر" را به انواع "بزرگ‌تر" تبدیل می‌کند بدون اینکه مقداری از دست برود (Promotion).

- **قوانین اصلی:**
    
    1. اگر یکی از اپراندها `long double` باشد، دیگری به `long double` تبدیل می‌شود.
        
    2. در غیر این صورت، اگر یکی `double` باشد، دیگری به `double` تبدیل می‌شود.
        
    3. در غیر این صورت، اگر یکی `float` باشد، دیگری به `float` تبدیل می‌شود.
        
    4. در غیر این صورت (فقط اعداد صحیح)، `char` و `short` به `int` ترفیع می‌یابند.

### ۲. تبدیل کاراکتر به عدد

از آنجا که `char` در واقع یک عدد صحیح کوچک است، می‌توان به راحتی روی آن محاسبات انجام داد. یک مثال کلاسیک از کتاب K&R، تابع تبدیل رشته عددی به صحیح است:

```c
int atoi(char s[]) {
    int i, n;
    n = 0;
    for (i = 0; s[i] >= '0' && s[i] <= '9'; ++i)
        n = 10 * n + (s[i] - '0');
    return n;
}
```

- **نکته علمی:** عبارت `s[i] - '0'` مقدار عددی کاراکتر را به دست می‌آورد. مثلاً اگر کد اسکی `'5'` برابر ۵۳ و `'0'` برابر ۴۸ باشد، حاصل تفریق دقیقاً عدد ۵ خواهد بود.

### ۳. تبدیل در زمان مقداردهی (Assignment Conversion)

در دستوراتی مثل `i = f` (که `i` صحیح و `f` اعشاری است)، مقدار سمت راست به نوع سمت چپ تبدیل می‌شود.

- **هشدار:** اگر یک `float` به `int` تبدیل شود، بخش اعشاری کاملاً **قطع (Truncate)** می‌شود.
    
- اگر نوع مقصد برای ذخیره مقدار مبدأ کوچک باشد (مثلاً ریختن `int` بزرگ در `char`)، داده‌های اضافی حذف شده و مقدار خراب می‌شود.

### ۴. تبدیل اجباری یا کستینگ (Casting)

اگر بخواهید به صورت صریح به کامپایلر بگویید که نوع یک متغیر را تغییر دهد، از اپراند `cast` استفاده می‌کنید:

`(type-name) expression`

**مثال:**

```c
sqrt((double) n)
```

در اینجا مقدار `n` قبل از ارسال به تابع `sqrt` به `double` تبدیل می‌شود. خود متغیر `n` تغییری نمی‌کند، بلکه یک کپی موقت از آن با نوع جدید ساخته می‌شود.
