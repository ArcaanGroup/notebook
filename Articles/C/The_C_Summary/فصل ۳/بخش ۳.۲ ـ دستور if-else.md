دستور `if-else` برای تصمیم‌گیری بر اساس یک شرط استفاده می‌شود. ساختار رسمی آن به شرح زیر است:

```c
if (expression)
    statement1
else
    statement2
```

### نکات فنی مهم K&R:

- **اختیاری بودن `else`:** بخش `else` اختیاری است. اگر شرط غلط باشد و `else` وجود نداشته باشد، برنامه به خط بعدی می‌رود.
    
- **ابهام در `else` (Dangling else):** این یکی از نکات کلاسیک در C است. اگر چندین `if` پشت سر هم داشته باشیم و فقط یک `else` وجود داشته باشد، آن `else` متعلق به **نزدیک‌ترین `if` قبلی** است که `else` ندارد.

**مثال ابهام:**

```c
if (n > 0)
    if (a > b)
        z = a;
    else
        z = b;
```

در اینجا `else` متعلق به `if (a > b)` است. اگر می‌خواهید `else` متعلق به `if (n > 0)` باشد، باید حتماً از براکت استفاده کنید:

```c
if (n > 0) {
    if (a > b)
        z = a;
}
else
    z = b;
```
