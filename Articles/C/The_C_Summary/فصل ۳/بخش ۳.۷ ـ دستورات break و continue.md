این دو دستور برای تغییر رفتار پیش‌فرض حلقه‌ها (و در مورد `break` برای `switch`) به کار می‌روند.

### ۱. دستور `break`

دستور `break` باعث خروج زودهنگام و کامل از داخلی‌ترین حلقه‌ی در حال اجرا (`for`, `while`, `do-while`) یا دستور `switch` می‌شود.

- **نکته فنی:** اگر حلقه‌های تو در تو داشته باشید، `break` فقط از حلقه‌ای که مستقیماً در آن قرار دارد خارج می‌شود و تأثیری روی حلقه‌های بیرونی ندارد.

### ۲. دستور `continue`

دستور `continue` شباهت ظاهری به `break` دارد، اما رفتار آن کاملاً متفاوت است. این دستور باعث می‌شود برنامه از باقی‌مانده‌ی بدنه حلقه در **دور فعلی** صرف‌نظر کند و بلافاصله به سراغ **دور بعدی** برود.

- **در حلقه `while` و `do-while`:** برنامه بلافاصله به بخش بررسی شرط می‌رود.
    
- **در حلقه `for`:** برنامه ابتدا به بخش "گام حرکت" (increment step) می‌رود و سپس شرط را چک می‌کند.

**مثال کاربردی:**

اگر بخواهیم فقط کاراکترهای غیرعددی را در یک رشته پردازش کنیم:

```c
for (i = 0; s[i] != '\0'; i++) {
    if (isdigit(s[i]))
        continue; /* از اعداد بپر و برو دور بعدی */
    /* پردازش کاراکترهای غیرعددی در اینجا */
}
```
