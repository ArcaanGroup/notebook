C دو عملگر منحصر به فرد برای اضافه یا کم کردن عدد **۱** از متغیرها دارد:

- `++`: اضافه کردن ۱ واحد
    
- `--`: کم کردن ۱ واحد

### تفاوت پیشوندی و پسوندی (Prefix vs Postfix)

این یکی از پرتکرارترین سوالات در آزمون‌ها و مصاحبه‌های فنی است:

1. **پیشوندی (`++n`):** اول متغیر را زیاد می‌کند، سپس از مقدار جدید در عبارت استفاده می‌کند.
    
2. **پسوندی (`n++`):** اول از مقدار فعلی در عبارت استفاده می‌کند، سپس متغیر را زیاد می‌کند.

**مثال عددی:**

```c
int x = 5;
int y = ++x; // x می شود 6 و y هم 6 می شود

int a = 5;
int b = a++; // b می شود 5 و بعد a می شود 6
```
