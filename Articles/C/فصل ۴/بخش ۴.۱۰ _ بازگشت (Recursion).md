توابع در C می‌توانند خودشان را فراخوانی کنند. این ویژگی **Recursion** نامیده می‌شود.

**مثال کلاسیک: چاپ یک عدد به صورت رشته (`printd`)**

این تابع برای چاپ عدد، ابتدا خودش را با مقادیر کوچک‌تر فراخوانی می‌کند تا به اولین رقم برسد:

```c
#include <stdio.h>

/* printd: print n in decimal */
void printd(int n)
{
    if (n < 0) {
        putchar('-');
        n = -n;
    }
    if (n / 10)
        printd(n / 10); /* فراخوانی بازگشتی */
    putchar(n % 10 + '0');
}
```

### نکات کلیدی بازگشت:

- **پشته (Stack):** هر بار که تابع خودش را فراخوانی می‌کند، مجموعه‌ای از متغیرهای محلی جدید در پشته ایجاد می‌شود.
    
- **مزیت:** کد را بسیار تمیزتر و منطقی‌تر می‌کند (مخصوصاً برای ساختارهای داده‌ای مثل درخت‌ها).
    
- **عیب:** از نظر حافظه نسبت به حلقه‌ها مصرف بیشتری دارد.
