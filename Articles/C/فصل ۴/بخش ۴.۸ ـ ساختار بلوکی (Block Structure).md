زبان C به معنای دقیق کلمه "Block-structured" نیست (مانند پاسکال که اجازه می‌دهد تابعی را درون تابع دیگر تعریف کنید)، اما اجازه می‌دهد متغیرها را در ابتدای هر **بلوک** (هر چیزی که بین `{ }` قرار می‌گیرد) تعریف کنید.

### ویژگی‌های متغیرهای بلوکی:

- متغیرهایی که در ابتدای یک بلوک تعریف می‌شوند، متغیرهای قبلی با همان نام را در بلوک‌های بیرونی "مخفی" می‌کنند.
    
- این متغیرها تا رسیدن به علامت `}` انتهای همان بلوک معتبر هستند.

**مثال:**

```c
if (n > 0) {
    int i;  /* این متغیر 'i' فقط مخصوص این بلوک 'if' است */
    for (i = 0; i < n; i++)
        ...
}
```

- **نکته علمی:** اگرچه این قابلیت وجود دارد، اما K&R توصیه می‌کنند برای جلوگیری از سردرگمی، بهتر است از نام‌های مشابه برای متغیرهای متفاوت در یک تابع استفاده نشود.
