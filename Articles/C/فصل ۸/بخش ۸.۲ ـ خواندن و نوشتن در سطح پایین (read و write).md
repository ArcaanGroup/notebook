این دو تابع، نان و کره (اساسی‌ترین ابزار) ورودی و خروجی در یونیکس هستند.

### ۱. تابع `read`

```c
int n_read = read(int fd, char *buf, int n);
```

- **`fd`**: توصیف‌گر فایل.
    
- **`buf`**: آرایه‌ای که داده‌ها در آن ریخته می‌شوند.
    
- **`n`**: تعداد بایتی که می‌خواهیم بخوانیم.
    
- **خروجی**: تعداد بایت‌هایی که **واقعاً** خوانده شده است (اگر ۰ باشد، یعنی به انتهای فایل رسیده‌ایم).

### ۲. تابع `write`

```c
int n_written = write(int fd, char *buf, int n);
```

این تابع داده‌ها را از بافر برداشته و در فایل می‌نویسد. اگر خروجی با `n` برابر نباشد، یعنی خطایی رخ داده است.
