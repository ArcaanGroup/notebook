همان‌طور که در فصل اول دیدیم، C از روش **Call by Value** استفاده می‌کند؛ یعنی توابع نمی‌توانند متغیرهای اصلی را تغییر دهند. اما با استفاده از اشاره‌گرها، می‌توانیم این محدودیت را دور بزنیم (چیزی شبیه به Call by Reference).

### مثال کلاسیک: تابع `swap`

اگر بخواهیم مقادیر دو متغیر را با هم جابجا کنیم، این کد **اشتباه** است:

```c
void swap(int x, int y) { /* کار نمی‌کند */
    int temp = x;
    x = y;
    y = temp;
}
```

چون فقط کپیِ مقادیر جابجا می‌شوند. نسخه **درست** با اشاره‌گر:

```c
void swap(int *px, int *py) {
    int temp = *px;
    *px = *py;
    *py = temp;
}
// فراخوانی در main:
swap(&a, &b);
```
