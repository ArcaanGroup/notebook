در زبان C، ورودی و خروجی (I/O) بر اساس مدلی ساده طراحی شده است: تمام داده‌ها، فارغ از اینکه از کجا می‌آیند (کیبورد، فایل یا شبکه)، به عنوان **جریانی از کاراکترها (Stream of characters)** دیده می‌شوند.

کتاب بر دو تابع اساسی تمرکز می‌کند:

- **`getchar()`**: هر بار که فراخوانی می‌شود، کاراکتر بعدی ورودی را می‌خواند.
    
- **`putchar(c)`**: کاراکترِ موجود در متغیر `c` را در خروجی چاپ می‌کند.

---

### ۱.۵.۱: کپی کردن فایل (File Copying)

ساده‌ترین برنامه برای درک این موضوع، برنامه‌ای است که هر چه در ورودی می‌گیرد را در خروجی بنویسد (مانند دستور `cat` در لینوکس).

```c
#include <stdio.h>

main()
{
    int c;

    c = getchar();
    while (c != EOF) {
        putchar(c);
        c = getchar();
    }
}
```

#### چرا از `int` برای ذخیره کاراکتر استفاده کردیم؟

این یکی از ظریف‌ترین نکات علمی کتاب است. متغیر `c` باید به اندازه‌ای بزرگ باشد که علاوه بر تمام کاراکترهای ممکن، یک مقدار خاص به نام **`EOF`** (مخفف End of File) را هم نگه دارد.

- `char` برای نگه داشتن کاراکترهاست، اما مقدار `EOF` عددی است که در محدوده بایت‌های یک کاراکتر معمولی جا نمی‌شود.
    
- بنابراین از **`int`** استفاده می‌کنیم تا مطمئن شویم فضا برای `EOF` وجود دارد.

---

### ۱.۵.۲: شمارش کاراکترها (Character Counting)

در این بخش یاد می‌گیریم چطور تعداد کاراکترهای ورودی را بشماریم.

```c
#include <stdio.h>

main()
{
    long nc;

    nc = 0;
    while (getchar() != EOF)
        ++nc;
    printf("%ld\n", nc);
}
```

- **`++nc`**: در اینجا از عملگر افزایش واحد استفاده شده که معادل `nc = nc + 1` است.
    
- **`%ld`**: برای چاپ متغیرهای از نوع `long` (اعداد صحیح بلند) استفاده می‌شود.

---

### ۱.۵.۳: شمارش خطوط (Line Counting)

زبان C با خطوط جدید (Newlines) دقیقاً مثل بقیه کاراکترها رفتار می‌کند. برای شمارش خطوط، کافی است تعداد کاراکترهای `\n` را بشماریم:

```c
#include <stdio.h>

main()
{
    int c, nl;

    nl = 0;
    while ((c = getchar()) != EOF)
        if (c == '\n')
            ++nl;
    printf("%d\n", nl);
}
```

- **نکته علمی:** عبارت `(c = getchar()) != EOF` نشان می‌دهد که در C، عمل انتساب خود دارای یک مقدار است. این کار باعث می‌شود کد فشرده‌تر و خواناتر شود (یک بار خواندن و مقایسه همزمان).

---

### ۱.۵.۴: شمارش کلمات (Word Counting)

این مثال کمی پیچیده‌تر است و مفهوم **State (وضعیت)** را معرفی می‌کند. برنامه باید تشخیص دهد که آیا در حال حاضر "داخل" یک کلمه است یا "خارج" از آن.

```c
#define IN  1  /* inside a word */
#define OUT 0  /* outside a word */

main()
{
    int c, nl, nw, nc, state;

    state = OUT;
    nl = nw = nc = 0;
    while ((c = getchar()) != EOF) {
        ++nc;
        if (c == '\n')
            ++nl;
        if (c == ' ' || c == '\n' || c == '\t')
            state = OUT;
        else if (state == OUT) {
            state = IN;
            ++nw;
        }
    }
    printf("%d %d %d\n", nl, nw, nc);
}
```

- **عملگر `||`**: به معنی **یا (OR)** است. شرط درست است اگر کاراکتر فاصله، یا خط جدید، یا تب باشد.

- تمرین ۱-۱۲: برنامه‌ای بنویسید که هر کلمه ورودی را در یک خط جداگانه چاپ کند.
