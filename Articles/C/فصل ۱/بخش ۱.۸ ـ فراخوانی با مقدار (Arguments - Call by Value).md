در زبان C، تمام آرگومان‌های توابع به صورت **"Call by Value"** منتقل می‌شوند. این یعنی وقتی متغیری را به تابع می‌فرستید، خودِ متغیر به تابع داده نمی‌شود، بلکه یک **کپی (Copy)** از مقدار آن در اختیار تابع قرار می‌گیرد.

### ۱. پیامد علمی این رفتار

چون تابع روی یک کپی کار می‌کند، نمی‌تواند مقدار متغیر اصلی در تابع فراخوان‌کننده (مثلاً `main`) را تغییر دهد.

**مثال از تابع `power` اصلاح شده:**

در نسخه قبلی از یک متغیر `i` برای حلقه استفاده کردیم. اما می‌توانیم مستقیماً از پارامتر `n` استفاده کنیم و آن را کم کنیم، بدون اینکه نگران باشیم مقدار `n` در جای دیگر برنامه خراب شود:

```c
int power(int base, int n)
{
    int p;
    for (p = 1; n > 0; --n)
        p = p * base;
    return p;
}
```

در اینجا هر چقدر هم که `n` تغییر کند، مقدار متغیری که در `main` به جای این `n` قرار داده شده بود، **ثابت** می‌ماند.

### ۲. استثنای مهم: آرایه‌ها

زمانی که نام یک **آرایه** را به عنوان آرگومان به تابع می‌دهید، C مقدار کل آرایه را کپی نمی‌کند (چون حافظه زیادی می‌گیرد). در عوض، آدرس شروع آرایه را می‌فرستد. بنابراین، اگر تابع تغییری در عناصر آرایه ایجاد کند، آن تغییر در آرایه اصلی نیز اعمال می‌شود.
