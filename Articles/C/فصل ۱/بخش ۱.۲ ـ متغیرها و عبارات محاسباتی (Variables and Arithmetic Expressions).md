K&R برای آموزش این بخش از برنامه‌ای استفاده می‌کند که جدولی از درجات فارنهایت و معادل سلسیوس (سانتی‌گراد) آن‌ها را چاپ می‌کند. فرمول مورد استفاده این است: $C = (5/9)(F-32)$.

### ۱. کد نمونه (نسخه اعداد صحیح)

```c
#include <stdio.h>

/* print Fahrenheit-Celsius table
   for fahr = 0, 20, ..., 300 */
main()
{
    int fahr, celsius;
    int lower, upper, step;

    lower = 0;      /* lower limit of temperature table */
    upper = 300;    /* upper limit */
    step = 20;      /* step size */

    fahr = lower;
    while (fahr <= upper) {
        celsius = 5 * (fahr - 32) / 9;
        printf("%d\t%d\n", fahr, celsius);
        fahr = fahr + step;
    }
}
```

### ۲. نکات کلیدی و علمی این بخش

- **اعلان متغیرها (Declaration):** در C تمام متغیرها باید قبل از استفاده تعریف شوند. در اینجا `int` نشان‌دهنده عدد صحیح است.
    
- **حلقه `while`:** شرط داخل پرانتز بررسی می‌شود؛ اگر درست باشد، بدنه حلقه (بین `{ }`) اجرا می‌شود و این کار تا زمانی که شرط غلط شود ادامه می‌یابد.
    
- **چالش تقسیم اعداد صحیح:** در عبارت `5 * (fahr - 32) / 9` دقت کنید که چرا ابتدا ضرب در ۵ انجام شده؟
    
    - اگر می‌نوشتیم `(5 / 9) * (fahr - 32)`، چون در C تقسیم دو عدد صحیح که حاصلش کمتر از یک است **صفر** می‌شود، کل نتیجه همیشه صفر می‌شد!
        
- **فرمت‌دهی خروجی (`%d`):** در تابع `printf` از `%d` برای جایگذاری یک عدد صحیح استفاده می‌شود. `\t` نیز یک فاصله (Tab) بین دو ستون ایجاد می‌کند.

### ۳. استفاده از اعداد اعشاری (Floating Point)

نویسندگان در ادامه اشاره می‌کنند که نسخه قبلی دقیق نیست (چون بخش اعشاری دما حذف می‌شود). برای دقت بیشتر باید از نوع `float` استفاده کرد:

```c
float fahr, celsius;
// ...
celsius = (5.0 / 9.0) * (fahr - 32.0);
printf("%3.0f %6.1f\n", fahr, celsius);
```

- **`%3.0f`**: یعنی عدد اعشاری را در فضایی به عرض ۳ کاراکتر و بدون رقم اعشار چاپ کن.
    
- **`%6.1f`**: یعنی عدد را در فضایی به عرض ۶ کاراکتر و با ۱ رقم اعشار چاپ کن.
