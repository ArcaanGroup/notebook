رایج‌ترین نوع آرایه در C، آرایه‌ای از کاراکترهاست که برای ذخیره متن (Strings) استفاده می‌شود. K&R در این بخش برنامه‌ای می‌نویسد که طولانی‌ترین خط ورودی را پیدا و چاپ کند.

### ۱. مفهوم رشته در C

یک رشته در C به صورت آرایه‌ای از کاراکترها تعریف می‌شود که در انتها به کاراکتر **`\0` (null character)** ختم می‌گردد. این کاراکتر به کامپایلر می‌گوید که رشته کجا تمام شده است.

### ۲. توابع کمکی در مثال کتاب

برای حل مسئله "طولانی‌ترین خط"، کتاب دو تابع تعریف می‌کند:

1. **`getline`**: یک خط را می‌خواند، در آرایه ذخیره می‌کند و طول آن را برمی‌گرداند.
    
2. **`copy`**: محتوای یک آرایه را در دیگری کپی می‌کند (برای ذخیره کردن طولانی‌ترین خط پیدا شده).

```c
#include <stdio.h>
#define MAXLINE 1000

int getline(char s[], int lim);
void copy(char to[], char from[]);

/* print longest input line */
main()
{
    int len, max;
    char line[MAXLINE], longest[MAXLINE];

    max = 0;
    while ((len = getline(line, MAXLINE)) > 0)
        if (len > max) {
            max = len;
            copy(longest, line);
        }
    if (max > 0) /* there was a line */
        printf("%s", longest);
    return 0;
}
```

- **`%s` در printf**: برای چاپ کردن یک رشته (تا رسیدن به `\0`) استفاده می‌شود.
