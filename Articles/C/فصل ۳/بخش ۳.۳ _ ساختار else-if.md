این ساختار در واقع حالت خاصی از `if-else`های تو در تو است که برای تصمیم‌گیری بین چندین حالت مختلف (Multi-way decision) استفاده می‌شود.

```c
if (expression)
    statement
else if (expression)
    statement
else if (expression)
    statement
else
    statement
```

### ویژگی‌ها:

1. شرط‌ها از بالا به پایین بررسی می‌شوند.
    
2. به محض اینکه یک شرط درست باشد، بخش مربوط به آن اجرا شده و کل زنجیره تمام می‌شود.
    
3. بخش `else` نهایی (اختیاری) زمانی اجرا می‌شود که **هیچ‌کدام** از شرط‌های قبلی درست نباشند. این بخش معمولاً برای مدیریت خطا یا حالت پیش‌فرض (Default) بسیار مفید است.
