دستور `switch` یک تصمیم‌گیرنده چندگانه است که بررسی می‌کند آیا یک عبارت با یکی از چندین مقدار **ثابت صحیح** برابر است یا خیر.

### ۱. ساختار دستور:

```c
switch (expression) {
    case const-expr: statements
    case const-expr: statements
    default: statements
}
```

### ۲. قوانین و نکات کلیدی (بر اساس K&R)

- **نوع داده:** عبارتی که در `switch` بررسی می‌شود حتماً باید **صحیح (Integer)** یا کاراکتر باشد. نمی‌توان از `float` یا رشته‌ها در اینجا استفاده کرد.
    
- **برچسب `default`:** این بخش اختیاری است و زمانی اجرا می‌شود که هیچ‌کدام از `case`ها با عبارت مطابقت نداشته باشند. توصیه می‌شود همیشه برای مدیریت حالت‌های پیش‌بینی نشده، آن را بنویسید.
    
- **نقش حیاتی `break`:** این یکی از مهم‌ترین نکات است. در C، وقتی یک `case` اجرا می‌شود، برنامه به طور خودکار به `case` بعدی "سقوط" می‌کند (Fall-through)، مگر اینکه از دستور `break` استفاده کنید.

### ۳. مفهوم Fall-through (سقوط به مورد بعدی)

گاهی اوقات "سقوط" آگاهانه استفاده می‌شود تا چندین حالت یک عمل واحد را انجام دهند:

```c
switch (c) {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        vowelcnt++;
        break;
    default:
        othercnt++;
        break;
}
```

در این مثال، اگر `c` هر کدام از حروف صدادار باشد، همگی به یک دستور ختم می‌شوند.
